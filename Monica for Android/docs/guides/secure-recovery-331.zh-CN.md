# Monica Android 恢复保护使用教程

适用于 1.0.331 的恢复保护功能，普通版与 F-Droid 操作相同。

## 现在还能正常打开 Monica

1. 使用当前主密码登录 Monica。
2. 打开「设置」，搜索「恢复保护」，或进入「主密码与锁定」→「恢复保护」。
3. 点击「验证恢复保护」，输入当前主密码并确认。健康旧安装缺少独立恢复材料时，会通过现有安全流程补齐；已有材料只做验证。
4. 看到「本次会话已验证」和时间后，说明当前材料已完成独立解密演练。只有文件存在不会显示验证通过。
5. 从详情页进入「数据库与备份」，导出加密 ZIP，并保存到独立位置。妥善保管备份密码，最好在另一安装验证能否导入。

正常主应用密码登录成功后也会尝试一次后台验证。它不弹出额外登录门槛；失败不改变已经成功的登录结果。指纹登录不具备主密码，所以可能仍显示需要密码验证。验证进行中退出前台会撤销这次验证；锁定或材料发生变化后，先前的验证状态会失效，这是预期行为。

「已验证」不是永久保险：以后文件可能损坏，硬件绑定凭据也不一定能恢复。独立加密备份仍然必要。

## 卡在安全存储保护页面

先阅读页面原因和恢复材料说明，不要清除 Monica 数据、卸载应用或删除恢复文件。

### 页面有原主密码输入框和恢复按钮

1. 输入创建当前密码库所用的原主密码。
2. 点击恢复，阅读二次确认说明后确认。
3. Monica 验证独立材料，在当前可用的系统密钥环境中创建并读回独立配置；原数据和原配置保留。
4. 成功后回到正常登录页，再输入主密码登录。
5. 检查旧记录能否读取、新记录能否保存，完全关闭后重开再检查。
6. 如指纹不可用，进入设置中的指纹重新绑定流程；重新验证恢复保护并更新独立加密备份。

错误密码、取消、锁定或超时都不应切换到未验证的配置。恢复失败时保留现场，复制诊断信息，不反复重置密钥环境。

### 页面没有恢复按钮

| 页面说明 | 下一步 |
| --- | --- |
| 未找到独立恢复材料 | 优先恢复原密钥环境；正常登录后验证恢复保护。若有独立加密备份，在另一安装验证。 |
| 凭据更改后需重新准备 | 先恢复正常访问，再用当前主密码完成准备和验证。 |
| 材料已撤销 | 不能使用该材料恢复；保留原文件，恢复原环境或验证独立备份。 |
| 材料不完整或无效 | 保留原文件，不使用空文件或另一密码库的材料替换。 |
| 不支持的恢复格式 | 使用兼容的 Monica 版本，保留现有数据。 |
| 无法读取或尚未检查 | 解锁设备，等当前操作结束，再点重新检测；这不表示密钥已永久丢失。 |

## 最近改过 OMK 或其他系统密钥模块

`MISSING_MASTER_KEY / PREFLIGHT` 表示当前系统服务找不到原密钥，不能单凭它证明密钥被删除，也不能证明一定是 OMK 导致。

如果是刚把 Monica 加入 OMK 作用范围后出现问题，可在模块自身界面恢复变更前的 Monica 作用范围，再完全关闭并重新打开 Monica，点击重新检测。若密码库原本创建在 OMK 环境中，处理方向可能相反，应恢复创建该库时的原环境。

保留原模块配置、种子和密钥；不要靠卸载重装模块、更换 keybox 或重置种子反复试错。Monica 不申请 Root，也不会自动修改模块。

本次反馈中，用户停止使用 OMK 后恢复正常，支持原密钥仍存在、访问路径受到影响的解释。尚无证据确定该用户的恢复材料缺失或损坏。

## 复制诊断信息

故障页点击「复制诊断信息」，提供版本、构建、Android API、Code、Phase、Attempts 和 Recovery material 分类即可。不要发送主密码、备份密码、完整恢复文件、密钥或真实密码库。

如果原系统密钥和独立恢复材料都永久丢失，软件无法仅凭主密码重新推导随机数据密钥。提前验证恢复保护、保留独立加密备份，是这套方案的关键。
