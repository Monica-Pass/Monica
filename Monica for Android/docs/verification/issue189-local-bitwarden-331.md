# Issue #189：本地密码移动到 Bitwarden

未发布 1.0.331；普通版 code12。对应 [GitHub issue #189](https://github.com/Monica-Pass/Monica/issues/189)。

现有本地登录在编辑页改存 Bitwarden 时，旧流程进入要求归属不变的密码历史事务，触发 `Password ownership changed`，导致保存失败。修改前 checkout 在 MuMu 上稳定复现同一异常：四项确定性测试中，两个实际保存调用和一个真实编辑页保存均失败，普通跨库归属保护一项通过。基线不是发行用户包，用户小米设备未直接测试。

## 修改与保护

专用本地迁移事务只接受真正的本地来源和已认证、尚未绑定远端 cipher 的 Bitwarden 目标；检查当前完整来源行、同一 ID、目标会话、无原生库绑定、无旧历史绑定及原密码快照。历史旧密文在成功解密后转为现有 MDK 保护，保留历史 occurrence ID/date；密码实际变化才捕获旧值。普通 Bitwarden 编辑仍执行原有归属相等检查。

整组本机迁移、密码、历史及字段在同一个带全局和目标锁代检查的 Room 事务中提交，失败或取消时回滚。记录保留原 ID 和关联；此事务不承诺远端网络写入的原子性，也没有修改加密算法、KDF、格式、云端接口或 UI。

APK、mapping 与证书 SHA-256 见同目录 release JSON；安装包及原始私有数据只留本地任务目录，不作为交付物。

## 保留的失败和证据边界

最初基线三项批次中另外两项是重复主密码初始化夹具失败；修正夹具后以四项确定性复现为有效基线。`main-fixed01` 因新增测试的 DAO/result/crypto API 名称错误编译失败，原生产编译成功。修正测试后继续构建。普通版两次既有历史 UI 回归各为 24/25；只替换 Context 或改应用语言不足以改变 Compose 字符串资源，旧测试找不到英文 Cancel。测试补齐 LocalConfiguration/LocalResources 后，两版最终完整 42 项按原行为断言验收；未放宽断言、扩大超时或改生产界面。

部分中间构建总源冻结标记为 false，变化仅在 AndroidTest；逐文件哈希审计确认生产输入没有变化。最终两版测试构建总源冻结一致，5 个共享生产/测试文件字节一致。过往 kotpass XML 缓存不计入本轮 JVM 19 项。MuMu 首次输入框打开应用商店的环境诊断保留，恢复后继续真实 UI 验证。

验证仅限合成数据、MuMu Android15/API35/x86_64。未覆盖报告者 Android17/HyperOS 真机、其他 OEM/API/ABI、官方云服务、所有附件传输或掉电情形。保持用户原有应用和模拟器数据；未提交、推送、发布、留言或交付 APK。此前 UI 等无关改动保留。环境清理见本地任务 cleanup JSON。

清理完成：恢复原用户 0，只移除自有测试用户 10 和 7 个测试包，停止本任务启动的 MuMu2 与 ADB 服务；原实例、配置和数据盘保留。默认卸载因目标用户错误被拒绝，显式卸载本任务包后成功；首次立即删除用户失败，确认停止后重试成功，原始失败记录保留。
