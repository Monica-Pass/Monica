# 界面缩放滑钮连续滚动 — 1.0.331

修复界面缩放滑钮在整数刻度间看似不滚动的问题。原共用组件直接将每个整数值映射到终点角度，花形重复轮廓会掩盖这种跳变；DPI 每 1% 一档更容易观察到。生成器和 DPI 使用同一组件，没有单独关闭 DPI 动画。

MonicaSlider 现在用短暂的 80ms 线性过渡连接角度，在拖动时连续接受新目标，正反方向及 RTL 沿用原移动距离计算。首次测量直接采用当前位置，不从零空转；应用减少动画和系统关闭动画继续禁用旋转。没有更改范围、刻度、触觉节流、数值回调或 DPI 松手保存实现。保留 ImageToolbox Apache-2.0 来源和修改说明；恢复既有可编辑设计已经要求的滚轮行为，没有新增页面设计。
