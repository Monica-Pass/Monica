## 使用与保存行为

入口：本地 KeePass 数据库 → 选择数据库 → 管理数据库内容 → 对应栏「更多选项」→「比较与合并」。双栏入口带入所点栏的数据库；Monica 本地库、MDBX 和数据库目录不显示此入口。旧 KDBX 工具页也保留入口。

1. 选择当前库与另一份本地可用库或系统文件选择器提供的 KDBX，分别输入密码和可选密钥文件。
2. 审阅原生条目、字段保护位、分组、历史、附件、图标、CustomData、AutoType、回收站／模板及删除记录。按 UUID 和内容比较，缺失不自动视为删除，较新时间不自动覆盖。敏感字段默认隐藏。
3. 显式选择当前版本、另一版本；只有可以证明安全复制时才允许同时保留。无法完整保留的内容、引用歧义、缺失附件、身份冲突和分组循环阻止输出。
4. 输入新库密码，生成独立加密文件并重新解密验证，再由系统保存窗口写入新的空目标。两份输入不覆盖；来源变化、锁定、取消和过期结果均受门控。格式、加密算法和 KDF 沿用左侧来源，结果不使用输入密钥文件，也不自动连接云同步。

支持同一格式版本的 KDBX 3.1、4.0、4.1；不通过 Room 登录字段投影重建原生数据库。普通浏览、导入、同步和自动填充不启动比较任务。

## 保留的失败与修正

- 初始构建期间源码仍在变化，不作最终产物依据；早期密钥文件夹具和 SAX 异常包装断言问题保留，修正后相关测试通过。
- 初次 Android 引擎批次暴露 ICU 正则初始化异常，修正后两版加密文件测试通过。
- 实际 Release 暴露比较入口只接在旧工具页，现已补当前双栏管理器，并添加真实路由测试。
- F-Droid 首次新界面批次 21/22：横屏初始已显示双栏，测试无条件切换反而隐藏右栏。改为先观察并建立双栏状态，所有身份、返回和保存断言保留，最终两版 22/22。
- 两份 R8 重叠运行导致 F-Droid JVM 原生 mmap 内存失败；保留崩溃日志，串行重建通过，未降低产品检查。
- MuMu 应用堆上限 192 MiB，比较 Argon2 内存上限为其四分之一，原始 64 MiB 文件被拒绝。另建 32 MiB 合成夹具，不改变原文件或生产策略。首次夹具修改保留了 PyKeePass RawCopy 旧头而无效；失败保留，新夹具先由两个独立工具重开验证再使用。
- MuMu shell 的 `content` 工具在完成操作后退出 139；首次 stdin 传输截断失败保留。最终传输按 MediaStore 长度和完整字节核验，读取尾部工具诊断单独识别，未把它混入 KDBX 或当作 Monica 崩溃。
- UI 驱动的本地数据库中间页、重复标题和横屏滚动坐标不匹配保留；按实际控件状态修正，不跳过产品断言。

## 明确边界与剩余风险


1. 不支持 `.kdb`、MDBX、Bitwarden、跨格式转换、不同 KDBX 格式版本配对或硬件挑战响应解锁。不能将“KDBX 3/4 可读”泛化为全部扩展无损支持。
2. 未知 XML 元素／属性、关键重复节点和当前模型不能保留的数据进入阻止路径；CustomData 的未知键值作为原生不透明内容保留。复制可能包含引用或 Passkey 的身份时采取保守限制。
3. 只有选定内容和历史所需附件进入结果；原本未被条目引用的附件有独立审阅行。缺失附件不能当作空文件。
4. 引用支持当前明确识别且能唯一解析的标准选择器。无法证明其意义保持的情况阻止输出；不声称任意插件占位符或任意 KeePass 客户端扩展都支持。
5. 单份输入限制 32 MiB；比较解码时，KDBX 3/4 整体解压流在缓冲及内层附件读取前限制为 64 MiB；XML 另限制 64 MiB、50 万节点、128 层。KDBX 3 XML 内嵌的压缩附件预扫描使用固定缓冲，附件展开总量另限 64 MiB。AES-KDF 上限 1000 万轮；Argon2 内存上限为 256 MiB 与当前进程最大堆四分之一的较小值，迭代上限 100、并行度上限 32。超限拒绝，不自动降低参数。
6. 解压流限制为 kotpass 解码新增的可选参数，默认不限制；本功能的输入比较和结果重开显式传入上限，普通开库调用保持原默认行为。此限制约束内容字节数，不能当作整个进程的堆内存硬上限，也不声称完全隔离所有恶意 KDBX 资源消耗。JVM 测试覆盖压缩 XML、4.x 内层附件、恰好达到上限与默认正常开库；比较测试另覆盖 3.x 嵌套压缩附件，相应 JVM 与设备回归已通过。
7. 明文比较信息仅在内存生命周期中存在，未写入日志或持久化页面状态；JVM String 无法承诺即时物理清零。关闭流程撤销引用与写入权限，不作不可验证的内存零残留承诺。
8. 内部结果原生重开验证后，外部保存还核对传输字节。系统文档提供器若不支持所需的本地可验证写入语义，则操作失败；未验证所有 OEM、USB、云文档提供器和断电行为。
9. 新结果不自动建立同步关系；显式选择云文档提供器不属于本功能主动联网。未对真实用户密码库、真实云账号或全平台互操作作验收承诺。
