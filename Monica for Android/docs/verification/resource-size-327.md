# Android 1.0.327 资源体积与旧 PNG 兼容验证

2026-11-11；普通版与 canonical F-Droid 的本地 main。仅优化内置图片、重复 Monica 图标及依赖语言资源；保留任务开始时的 KDF、Send、NFC、KeePass 等既有改动。未提交、推送、发布或交付安装包。版本保持 1.0.327（普通 code12／FD34）。

## 已实现与兼容范围

- 1079 个品牌 PNG 转为 1078 个无损 WebP，重复的 Monica asset 复用原 drawable 标识。加上 launcher，共 1080 份原始图像逐一验证尺寸和完整 RGBA（含透明通道）相同。838 个旧 slug、原标签顺序、1676 个明暗来源选择保留。
- 两张赞赏图保留 3525×1800／2516×1280 分辨率，采用 quality 95 WebP，分别从 1128710／565625 降到 155046／103652 字节。主代理查看了新图；主机及 Android 实际扫码器在原尺寸、1200、800 宽度均核对全部 4 个原二维码 payload 哈希，不公开付款内容。放大与保存流程仍保存 PNG。
- 已存项目的 UPLOADED PNG 原文件名、内容、复制与 ZIP 备份恢复保持不变；新上传仍按原 PNG 路径保存。SIMPLE_ICON 仍保存裸 slug，未知带扩展名的历史值不被擅自改写。旧 PNG 磁盘缓存目录、版本及文件名不变。内置资源读取同时支持 PNG/WebP。未改数据库、上传图标存储、WebDAV、KeePass 或 LAN 图标格式。
- 使用 29 项精确 localeFilters，保留全部应用语言、lzh、Hant、zh-rNY／zh-rXB、两种葡语及原依赖受支持语言的地区变体。AAPT 实验证实裸 zh／pt 不自动保留地区配置，因此显式列出。自有字符串 XML 未删改；过滤 65 个额外 locale 配置。

普通首次设备批次18/19，唯一失败是新测试错误假设缺失古汉语条目会按配置列表逐条退到简中。旧生产 APK 对照同样得到默认英文；旧批次3/5另含预期的未过滤Arabic依赖负控。修正夹具后先在旧 APK 独立运行古汉／繁中方法1/1、0.071秒，再验证新版。保留精确古汉/繁中翻译、locale列表和显式简中资源断言，未改生产 LocaleHelper，也不承诺逐条向Hans回退。

FD初次静态资源检查报告2项缺失：qs_import_from_apps及_desc只有意大利语定义且无默认值，AAPT在新旧包均剔除；相关源文件与任务基线相同。比较器保留该诊断，区分基线已有缺失与新增缺失，最终新增缺失为0；未按资源名称硬编码豁免。普通1456、FD1471份语言XML均与任务起点逐字节相同，全部配置/编译值检查保持。旧失败回执保留。

## 一致性、清理与边界

两版1088个本任务共享资源／源码／测试文件字节一致。普通5246、FD5239个构建输入文件与最终冻结清单一致；任务起点app范围内的生产变化仅有图片、内置图标加载和locale过滤。发行说明用一条面向用户的资源优化说明，原KeePass拆分仍合并；FD元数据和6项脚本测试通过。

清理前后原用户0／10的包清单相同，恢复0，仅删除本任务guest11；停止自启MuMu0并核对Android及模拟器进程均停止，原实例与数据盘保留。公共AVD未使用。首次清理探测用到不支持的is-user-running命令，在删除前停止；改为支持的am get-started-user-state确认已停止后完成清理。冻结辅助脚本首次把app-only基线与全工程清单作差，纠正比较范围后通过；不属于源码回退。

本轮是合成数据、API35/x86_64/Debug验证，未做Release/R8、真机/OEM、API26或真实云同步测试。二维码压缩有损且保持payload，品牌图标无损。自动图标匹配冷／暖路径未请求favicon，不泛化为所有显式图标路径都不联网。

本目录 resource-size-327.json 保存编译值结果、APK哈希／分项大小、构建／测试统计及清理回执。原始构建／失败／基线对照日志、图片基线、全输入哈希、独立审查和逐ZIP条目证据保存在本地任务 `.codex-tasks/20261110-resource-size-327/`；未把图片或APK加入文档。先前KDF任务证据保持独立。
