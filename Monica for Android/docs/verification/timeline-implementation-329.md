# 时间线 329 实施与验收

普通版与 canonical F-Droid 已完成本机时间线、字段恢复及只读来源聚合，保持未发布 1.0.329（普通 code12 / F-Droid36）。完整设计中的原生统一恢复、完整历史副本和跨库逐项操作仍未开放，不能把本轮当成所有设计阶段全部完成。

## 行为与边界

- Room schema85 →86 新增事件与目标表；标题、差异与恢复材料封装加密，旧日志及旧快照保留。
- 本机密码、安全项目、自定义字段在原授权事务内写入；多密码一次编辑归为同一事件，失败或取消一起回滚。未知/原生来源只保留经脱敏的观察事实，不能用 Room 投影回滚原库。
- 变更、可恢复、同步分栏；按库/日期筛选，稳定游标分页，搜索项目名、字段和动作，不搜索秘密值。同库同自然日、明确零变更的自动同步折叠；130次同步不会截掉用户编辑。
- 本机独立字段先预览再确认。确认重新核验原始行、自定义字段、附件、锁代、材料及期限；先保留被覆盖版本，再同事务恢复并写关联事件；重复执行 ID 不重复写入。
- 相同值重新加密不算内容变更；只保存字段等价标记，不新增明文比较索引。原始密文仍用于严格冲突校验，恢复其他字段时保留未变字段当前密文；未知/不可读值不判为相等。
- 身份、绑定、未知列、附件变动、Passkey和密钥项目不开放字段恢复；保留当前附件和密码历史。笔记只支持已知且没有内联图片引用的字段内容。没有完整性证明时不制造“完整历史副本”。
- 回收站沿原执行器与导航，精确定位类型/ID/库；本机恢复拒绝过时选择与锁定后的操作。旧日志只读，旧翻转撤销/重做入口不再接入。
- 本机新材料保留30天，读时立即检查期限；永久删除同时清理相关新旧恢复材料，保留无内容事实。独立备份不清理；新事件材料尚不包含在旧普通日志备份内。
- MDBX 可进入原有历史；KeePass/Bitwarden 原生历史统一恢复、跨库一键撤销、全部导入与同步的全局分组、远端逐项结果未实现。附件回归检查元数据和历史保留，不能代替附件 blob 的完整历史恢复。

## 发现与保留的失败

- main01新增测试的异构数组类型编译失败，修正后重建。
- main04导航回归20项中4失败：两个重复返回按钮的实际回归已修；MDBX夹具使用不存在ID、导航只允许底栏的旧断言分别改为真实合成目录与保留顺序/间距的rail或bottom断言。main05对应25项通过。原错误日志保留。
- main06跨修改时点构建，明确标记中间混合源码，未安装、不作最终证明；fd02为中间版本。
- main07/fd03各44项全过后，真实Release发现只改用户名也因随机密文被标成改密码。修前main08-red两个回归均失败（0.438秒），分别证实无值变化新增事件及重写未变自定义字段；修后main09/fd04整批46项通过，随后布局修正main10/fd05整批47项通过。没有删断言或扩大超时。
- 旧普通备份首次保存到MuMu映射Download目录被EACCES拒绝，改用Documents成功，未改变存储权限。首次导入原记录仍在，结果0（重复跳过）；删除本任务合成记录后导入1。最终两版均在各自旧版备份中恢复1项，保留最终包新增记录并在新进程读取；逐步UI回执保留。
- 中间new02混淆Release实际截图发现父页面返回悬浮按钮覆盖恢复按钮。为嵌入时间线预留104dp底部操作区，并新增恢复/取消与父按钮无交叠断言；生产存储逻辑不变，重跑两版整批并重新混淆构建。
- 中间普通new02 Release首次UI驱动遇到两个Show按钮而停止：导入项目第一次编辑同时初始化replica_group_id绑定，密码已正确不列为变更；该绑定事件应禁止恢复。用普通编辑器设回合成用户名、绑定稳定后重新执行完整流程，未改生产/断言或放宽绑定检查。原XML保留。
- new03普通首轮UI驱动未先滚动就查找Cancel，因预留底部操作区后该按钮在首屏之外而停止；补按实际可见性滚动，保留原XML及日志，未改生产/断言。
- 本地首次资源输出遇到终端GBK显示失败，完整dump已保存；随后显式UTF-8并核对资源。源码未因此改动。
