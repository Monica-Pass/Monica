# 1.0.328 多库自动填充验证 — 普通版

本轮功能、实际 R8 保留数据升级及入口阶段均取得通过结果，初次失败和复测限制保留。测试用户与模拟器的最终清理由主代理继续执行；版本仍未发布，没有交付安装包。

## 功能与安全范围

自动填充 V2 选择器按本地、指定 Bitwarden 账号、指定 KDBX 数据库、指定 MDBX 或全部来源准备凭据。Bitwarden 使用绑定来源与账号的查询；KDBX 只读取选中的原生文件，减少无关库准备，保留认证、锁定、取消与动作前核验。

MDBX 从实际原生库以请求独占的读取句柄和 disclosure 授权读取，核对文件/库身份、对象 UUID、collection、已知类型/载荷版本和当前 head revision。支持原生登录及受支持的银行卡、证件、地址。不可读、未知、冲突、归档或修订失效的对象不回退到 Room 镜像；归档映射只提供拒绝信息，不能提供凭据或授权。编辑保存回执只沿已证明的原生身份映射，不按标题或账号猜测。

系统原生建议 Dataset 不保存凭据值；实际 callback 重新读取，校验 storage、数据库/对象身份、修订、进程和 generation。原生值中类似密文的字面前缀保留，不重复解密。真实 MDBX framework 三方法覆盖系统建议到真实 callback 与外部表单、缓存建议后的外部修订拒绝、认证取消；真实编辑保存/取消另有 UI 测试。

MDBX 暂不支持绑定新网址：现有原生接口缺少条件修订写入能力，不写镜像冒充原生更新。独立密码键盘尚未接入本轮原生 MDBX 读取。最终重读与 Android 填写不构成跨进程原子事务。

## 初次失败与复测限制

- 普通旧包 MDBX 两项负向对照均预期失败：native-only 记录缺失、原文件不可读仍可能返回旧镜像。普通原生首批 27/30，后续 32/32；保留必需字段、重复 JSON key 被引擎规范化、不可变 type 等夹具及 parser/source 修正证据。
- 普通 UI 首批 6/9、第二批 8/11、framework 批次 26/31。分别修正无滚动父级菜单操作、同名节点选择、真实操作弹窗漏点 Fill、ActivityMonitor.hits 不统计入站系统 PendingIntent 的误断言。改为验证真实 callback Activity 及身份，原外部表单、修订和取消断言保留；后续 31/31。
- 普通旧回归批次 29/60，含过期虚拟 ID 预期和 KeePass 既有合成主密码不匹配；改为验证提前排除及使用独立合成用户，未降低认证。后续 KeePass 批次 19/30、19/30、28/30、29/30，保留语言和通知权限前提修正。
- 普通最后一项可见性失败在相同主/测试 APK 独立复测通过，原失败原因未确定。原 dump 含标题但没有当时可见性/窗口/bounds 证据，不能等同可见断言通过；随后成功运行的截图也不能反推首次没有遮挡或时序问题。没有因此修改生产时序或放宽等待。
- 普通初构建有测试夹具编译失败；FD 初次参数展开导致任务选择失败。FD 更完整 JVM 初批 1,097 中有 3 个历史源码结构断言失败；仅跟随既有持久化、认证门控和 folder resolver 更新断言，对应生产逻辑未改，两版最终完整 1,097 全部通过。普通早期 867 没有覆盖全部这三项，不能视为相同集合已通过。
- **两版首次 R8 pickerAuth 均缺少预期记录可见节点，随后同包、同探针复测通过，原原因仍未确定。** 普通首次 20.873s 后被驱动误包装为 target mismatch；调整失败报告顺序后，FD 首次 20.810s 正确报告 Entry phase did not pass。只修了诊断包装，未改变 probe 模板/APK、生产代码、超时或断言。普通/FD 成功复测 instrumentation 为 1.176s/1.090s；不能称首次整批全绿或生产问题已经修复。
- UI 导航与 dump 失败步骤保留。应用/文件选择器前台观察失败、uiautomator 输出后 139 等与实际应用崩溃分开；成功回执与原退出码同时保留。单次点击、文件存在或 instrumentation 结束时的 app died 不能独立证明恢复成功或生产崩溃。
