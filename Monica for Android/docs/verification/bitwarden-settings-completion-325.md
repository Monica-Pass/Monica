# Bitwarden 设置与个人库兼容收尾（1.0.325）

普通版与 canonical F-Droid 保持未发布 1.0.325（code12 / code32）。本轮只使用公共 API32 AVD 的独立合成用户，没有访问真实账号或用户密码库。组织／集合共享和高级认证按用户要求继续暂缓。

## 最终行为

- 设置页统一为24dp外角、4dp相邻内角，16dp页面边距。同步队列、自动同步与Wi-Fi限制组成连续分组；长说明使用完整行宽，安全提示独立放在卡片下方。添加账号移到顶栏，避免悬浮按钮遮挡内容，大字号允许顶栏标题换行。账号页保留明确身份与安全入口。
- 同步队列读取真实Room状态和附件意图，可查看失败明细并重试正确账号；锁定即撤销私有标题。Never lock的单次认证绑定选中账号，取消、切换账号和后台会撤销授权。
- 账号安全状态改变时，在原账号gate内完成已经开始的本地凭据撤销，避免界面重组取消导致内存已锁、持久凭据未清。网络及认证成功发布没有放入NonCancellable。
- 密码编辑支持附件保存、补传和删除。上传失败保留本地文件和意图，操作绑定精确所属账号与条目。
- 前台解锁时接收SignalR通知，经过现有调度器同步，重连补拉；后台、锁定、身份变化、网络与偏好门禁撤销监听及迟到任务。
- Send提供服务端允许的邮箱验证、加密缓存和加密文本／文件草稿，显式恢复并手动提交；不确定创建先按唯一精确加密key对账，避免重复POST。安全缓存清理保留dirty、未知或不可读记录；明确退出账号才清该账号草稿。移除访问密码由专用接口完成，普通PUT先保留原验证方式。
- 普通／密码加密Bitwarden JSON可导入Monica本地，从本地或已解锁个人Bitwarden库导出。五种类型、文件夹、可表达历史／网址规则等按预检处理，不能保真的字段整批拒绝；取消、锁定、后台及身份变化撤销授权，实际写出中途锁定清空部分输出。

两版150个共享文件SHA相同；MainActivity、Repository、ImportDataScreen、DataExportImportViewModel保留4处既有版本差异。65个新增字符串覆盖18配置（1170值），另15个已有安全提示移除嵌入emoji并使用原生图标；每版实际APK合计1185值逐项核对。

## 过程中的失败

- 初次集成设备测试编译把Flow当作StateFlow；修为first()。随后JVM手工AttachmentDao假实现漏3个新方法，补齐实现。两次构建失败保留，主APK形成不算整批通过。
- r2设备73项中64通过9失败：旧文字溢出判断误用段落约束、账号恢复前台未重拉、通知测试未推进Compose重组，以及Send开关可见性、保存busy和缓存夹具状态。修复生产问题或具体测试夹具；保留原功能断言与失败日志。
- r3 JVM157项中1项密码移除authType契约失败；修复普通PUT与专用移除的顺序，新增回归，不放宽原断言。
- r4 JVM158通过；设备76项中74通过2失败。完整大字号页需要先滚动创建LazyColumn中尚未加载的目标；账号安全用例暴露UI取消持久撤销的真实竞态，修复gate并新增确定性取消测试。
- 公共AVD重启后首个r4截图检查被系统锁屏挡住，1项失败；解锁后继续原合成用户，同安装包运行完整批次。失败和系统截图只留作诊断。

- r5两版各159项JVM通过，普通设备76项中75通过1失败、FD76项通过。普通版完整草稿相等检查发现动态默认时间戳可能在同一毫秒序列化时被省略，读取便生成新时间；修复为明确写入所有默认值，旧加密草稿缺时间戳时在验证成功后使用稳定文件时间且不改写文件。新增旧草稿回归，最终r6常规77项。原失败与完整相等断言均保留。

- 最终进程恢复驱动首版错误要求instrumentation结束后目标进程仍在，宿主断言失败；目标已退出。保留已通过的prepare，停止自有目标及测试包并确认全部进程消失后继续recover，未重做prepare或清数据。两版prepare/recover均实际通过，目标退出与fixture清理分开记录。

## 仍有的边界

- 不宣称完整Bitwarden客户端：组织／集合与高级认证暂缓；新blob、type6–8和CryptoV2／COSE上游实验能力未实现。
- 标准JSON不携带附件文件、Send或归档状态；账号绑定密文、组织数据及不可表达内容按严格预检拒绝。
- 通知不在应用被杀后后台常驻；没有独立notifications主机、自定义header配置或endpoint discovery。真实官方hub、自签CA／mTLS hub、双真机／OEM、真实Wi-Fi／VPN组合和401成功刷新设备路径未验证。
- Send草稿需显式恢复提交；未知文件上传结果必须有持久成功回执才能确认，文件元数据不能证明上传完成。未提供匿名收件全链，不保证历史SQLite WAL／freelist明文被擦除或无CAS服务端的原子覆盖。
- 本轮未做R8或用户真机验证。没有提交、推送、标签、发布或APK交付。
