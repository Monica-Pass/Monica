# 多选菜单配色与圆形按钮验证（1.0.331，未发布）

2026-11-25，普通版。底部多选菜单增加实色圆形按钮，菜单使用较亮的主题混色底色并移除外部描边。笔记、通行密钥复用共享组件，其他共享调用方同步生效。窄屏仅滚动操作区，数量与关闭按钮固定可见；操作回调和原有确认流程保留。

## 最终实现

- 菜单从最高层表面与 primary 混色获得默认颜色，不使用外圈 border；显式传入颜色仍受支持。
- 普通按钮使用 secondaryContainer，删除使用 errorContainer；图标与计数前景不足 4.5:1 时选择可读前景。菜单/卡片和按钮/菜单底色分离目标为 1.25:1，这不代表整款应用通过 WCAG 审计。
- 按钮触摸区域 48dp、图标 24dp；280dp、2 倍字号、RTL 和五位数计数可以滚动到操作，关闭按钮保持可见。
- 阅读 ImageToolbox 的 EnhancedIconButton.kt，参考圆形实色图标按钮视觉；本轮独立实现，没有复制该源码。参考提交 ab763ce76effd13ae3b8c7cfea37835eb9e0f8b9，README 已标注项目。既有滑块改编的 Apache-2.0 许可证和来源说明保留。
- 本轮新增资源字符串为 0，继续使用已有本地化标签。
