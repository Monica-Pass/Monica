# 台灣繁體中文驗證（未發布 1.0.331）

新增 `繁體中文（台灣）`，使用 `zh-Hant-TW` 與獨立 `values-b+zh+Hant+TW` 資源。採用軟體、資料庫、檔案、資料夾、網路、連接埠、身分、生物辨識、電子郵件、剪貼簿、金鑰與權杖等用詞；登入帳號和金融帳戶分別處理，技術支援與贊助支持依語境區分。

本版 130 個 XML 覆蓋目前全部 7,351 個可翻譯鍵。保留原香港語言值、列舉順序和全部香港資源原始位元組；中文分組分別顯示台灣與香港。`zh-TW` 和 `zh-Hant-TW` 判定為台灣，`zh-Hans-TW` 仍判定為簡體；香港、澳門和未指定地區的 Hant 保留既有選項。香港／澳門缺译項在 Android 的 Hant 地區回退規則下可使用新台灣譯文。

- 來源契約檢查保留資源類型、格式參數、具名權杖與明確換行；品牌、技術字串與 Auto-Type 權杖保留原文。普通版與 F-Droid 分別產生與驗證資源，保留平台專用差異。

## 保留的失敗與限制

普通版首次聯合運行 6 個 JVM 中 5/6，測試誤認香港生物辨識原文，改以實際「身份／身分」與「軟件／軟體」檢查；當時仍在潤飾翻譯，不作最終凍結構建。後續兩版各 7/7，生產來源与最终主包构建凍結值一致。

普通版首批設備 18/19，舊斷言預期香港缺譯項顯示英文；實際會回退到新台灣繁體，已按區域回退語義更新斷言。第二批仍 18/19，`taiwanCanBeSelectedSeparatelyFromHongKong` 出現 No compose hierarchies；日誌確認 09:59:29.936 宿主進入 RESUMED 時收到系統轉向配置，09:59:29.980 舊宿主銷毀、09:59:29.993 新宿主進入 RESUMED。未修改應用或降低斷言，同一主／測試包獨立選取用例 1/1 通過。普通版不宣稱整批全綠，未獨立修復通用 ActivityScenario 轉向競態。F-Droid 設備首批 19/19，另有兩項無遮擋視覺複測。

其他語言的既有缺譯項仍保留：起始靜態盤點香港缺 406 項，簡體通用包等其他語言也有既有缺項；本輪只為新台灣包驗證完整來源契約，沒有宣稱全語言資源完整。F-Droid 既有缺少預設值的快速設定資源警告保留。

仅驗證 Debug、合成設定、實際資源與代表 UI；未做台灣母語者全量校對、完整主 Activity 導航、每個頁面、實體裝置／OEM、R8 或 Release 升級驗證。快取測試包含重新建立設定讀取與清除記憶體鏡像後讀取，不等同真實跨行程重新啟動測試。
