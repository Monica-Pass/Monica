# Steam token display parity — unreleased 1.0.328

The actual SteamScreen card adapter wraps the imported Base64 key in a `steam://` value. The shared resolver removed leading/trailing `/` characters as though the key were a path. These are legal Base64 characters, so the displayed code used different bytes from direct Steam code copying. The maFile parser's `steam://` variant had the same trimming. Both editions now preserve the payload. The official uppercase Steam alphabet, HMAC-SHA1/30-second algorithm, URI priority, database format and encryption remain unchanged.

The pre-fix actual adapter produced FTHVB while direct Steam generation produced PMRRM. The failing JVM XML is retained locally.
