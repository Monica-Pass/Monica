# Android 1.0.327 安全问题找回加固验证

验证日期：2026-11-11 至 2026-11-12。普通版与 canonical F-Droid 使用相同共享实现；仍为未发布 1.0.327，普通 code 12、F-Droid code 34。

## 修复行为

初次设密码、验证旧密码修改、找回重置使用不同授权条件。`setMasterPassword` 拒绝替换已有主密码；已有运行时 MDK 或 COMPAT 包裹不能授权改密码。找回先验证两个安全答案，再通过仅允许 DEVICE_CREDENTIAL 的系统 BiometricPrompt 完成本次 PIN、图形或锁屏密码确认。导航布尔值只是页面参数，不能签发恢复许可。

恢复许可按对象身份绑定本次请求、存储、原凭据、问题答案、运行时锁代和密码凭据代；五分钟到期，一次消费，取消、页面卸载、后台、锁定、凭据/答案替换和后续请求使其失效。提交前重新核验，取消后迟到结果不能授权。恢复只读取已有 Keystore 包裹，不创建替代 MDK；缺失、损坏或无法解密时保留原材料并失败。COMPAT 包裹继续用于已有兼容功能，其存在不再替代恢复授权。

新答案使用 16 字节随机盐、PBKDF2-HMAC-SHA256／600,000 次以及版本化 `sq2` 编码，采用字节比较并限制输入和元数据大小。旧 SHA-256 仍兼容验证与备份读取；只有用户提供真实原答案且完成恢复授权后，才在密码凭据提交中迁移。旧 SHA 字符串不会当作用户答案重新哈希。新格式备份需要支持该格式的客户端，未承诺旧客户端能够读取新哈希。

尝试次数存于独立 no_backup 私有文件，使用进程内与文件锁、原子写入。哈希前预留次数，错误和中止尝试均计入；三次后等待十五分钟，跨页面和进程保留，状态损坏时拒绝尝试。它不承诺抵御 root、卸载重装或应用数据被外部删除。

Android 11 以下或没有可用系统锁屏凭据时，找回路径拒绝授权，保留原密码修改和独立备份恢复。AUTH 包裹仍可能因 Keystore 认证状态失败；本轮没有把系统凭据确认描述为在所有硬件状态下都能恢复原密钥。

TOTP、银行卡、证件的新敏感写入移除了缺少 SecurityManager 时的明文兜底，必须具备加密依赖；测试显式提供替身。原有历史明文／密文兼容读取逻辑保持原状，此处只改变新写入的依赖缺失与加密异常处理。此项是接口加固，未声称原生产入口已发生明文泄露。README 已区分本地主密码 600,000 次、历史 100,000 次／Argon2id，以及便携备份 V1／100,000 次、V2／600,000 次。

## 失败与限制

旧 Debug 包与新安全断言的负向对照在 `cachedOrCompatMdkIsNotResetAuthorization` 预期失败，证明暖 MDK 可调用旧替换接口；未泛化成所有 Keystore 状态下的攻击复现。修复后的同一方法在最终核心批次通过。

保留旧构建/夹具/源码守卫失败、普通早期使用旧测试包的四个保存超时、普通 core-device-04 的两项旧授权/固定调用次数断言失败。旧测试改为真实恢复许可，并在实际提交门控注入锁定，未放宽生产保护。F-Droid 最终主包联合运行的 JVM 曾 UP-TO-DATE，因后续两个安全源码文件变化，另行强制仅运行单测任务，最终 46 项实际通过；不把缓存复用算作新执行。

普通版下载 provider 拒绝导出 URI 写权限，应用受控失败且原库保留；改用系统主存储 provider 后原生导出通过。该下载 provider 拒绝未修复，未通过追加广泛存储权限绕过。个别 uiautomator 命令退出 139 但已生成 XML、冷启动瞬间返回空 root 等驱动观察错误保留；不计成应用崩溃或测试通过。

仅合成 MuMu API 35／x86_64，未做用户库、官方签名包、物理设备/OEM、真实 TEE、所有 AUTH 状态或 Android 8–10 的设备验证。没有新恢复密钥方案，也不保证硬件材料永久丢失后可恢复。没有发布、标签或 APK 交付。
