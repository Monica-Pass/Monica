# 密码库概览搜索过渡（1.0.329）

首批结果就绪时，列表从可用高度的 75% 处向上浮现，行程最多 360dp，标准时长 340ms。搜索框和键盘可以并行展开。筛选时列表按现有条目标识复用各行，使用 Material 3 的 fastSpatialSpec 调整位置，使用 fastEffectsSpec 淡入新匹配和空结果提示、淡出移除的结果。来源或索引变更时重建列表，关闭搜索或锁库时移除整个结果区。
