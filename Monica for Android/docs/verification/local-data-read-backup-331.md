# 本地密文读取与备份错误修复（未发布 1.0.331）

## 结论与范围

修复 Monica 已复现的读取及备份失败处理问题。用户提供的日志显示 C2 和 MDK 认证校验失败，来自从 330 降回 329 后的运行；本轮没有复现或定位该个案，也没有证据把它归因于外部检测工具。不能承诺本批修改恢复该用户的旧记录。

## 行为变化

- MDK/C2/V2 前缀识别与解码统一规范化外层空白；正常密码正文、普通明文的空白保留。此前真实 ZIP 会写入带空白的设备密文，现在可读值正确解密，损坏值继续阻止导出。
- ZIP 敏感字段读取失败携带所属项目标题，历史密码按 entryId 从快照取得所属标题。标题仅用于本机提示，不进入该异常的消息文本；保留 cause 供现有诊断使用。
- 备份提示说明读取失败、备份未完成、原数据保留，覆盖 21 个资源配置；不再对所有异常统一要求解锁。
- CancellationException 原样传播，结果卡片使用已有“已取消”文案。
- 未改变加密算法、KDF、数据格式或密钥生成／恢复流程，不因读取失败清库、创建替代密钥、跳过记录或保存不完整的成功备份。

## 修前对照

普通版真实 Debug / AndroidTest 构建后，7 个设备用例中 1 通过、6 预期失败：三种格式外层空白读取错误、损坏密文绕过解密、ZIP 写入密文以及错误缺少标题。21 个 JVM 用例中 2 个预期失败：取消被包装和异常文本包含标题。原始失败证据保留。

## 失败与限制

- 首次修前测试编译漏填 PasswordEntry 的 website/username，补夹具后成功；首次修后编译将历史记录误当作有 title，改为按所属项目查标题并增加历史失败用例后成功。保留两次编译失败记录。清理时默认用户卸载被拒后改为显式 user13；立即删除用户被拒后确认其停止状态再成功删除，原始回执保留。
