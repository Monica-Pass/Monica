# 物理密钥按需启用 — 1.0.327 验证

普通版与 canonical F-Droid 同步实现。物理密钥默认关闭，可在物理密钥管理页和重命名后的“自动填充与通行密钥”设置页切换；设置搜索使用新名称并可定位开关。“页面调整／自定义”未添加开关。

## 行为与边界

- 原因来自源码检查：原 Provider 用手机具有 USB Host/NFC 能力作为硬件候选条件，不代表已接入钥匙。
- 两个入口共用本机非敏感布尔偏好。关闭时不添加 Monica 的硬件候选，停止相关发现/连接；已有硬件目标请求取消，最终结果再检查状态。软件候选、密钥、认证和存储格式保持不变。
- 开启后保留 USB/NFC。NFC 贴近前无法可靠判断有没有钥匙，因此采用显式选择。系统或其他提供方的安全密钥入口由其自身控制。
- 硬件候选在软件凭据异步读取后按最新偏好添加；发现等待安全准备完成。前台标志、连接 epoch、延后消费授权及首次连接标志防止后台迟到结果、丢失授权和拒绝后反复请求。
- 生产 Manifest、密码验证、加密算法和浏览器证书白名单未改。已有 JVM 源码检查更新为当前共享有界密码验证的成功提交、失败及取消撤销检查。
