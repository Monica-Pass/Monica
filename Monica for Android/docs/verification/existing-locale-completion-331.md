## 首次失败与限制

普通首次主/测试包已打出，但 JVM 15/16：旧文言文用汉字数字且漏技术名，按上述 14 项修正后 16/16。一次资源写入脚本误以默认文件名定位已有翻译，写入前断言失败；后续命令仍启动了未修正的第二次测试，仍为同一旧失败。修正目标定位后主/测试/JVM 联合通过；初始日志保留。

翻译初稿出现接口限流、分段边界丢失，已保留原响应，严格核验相邻边界并手工补修后才写资源；安全提示、删除选择与技术词另行复核。普通首轮设备 9/34：24 项 UI 的测试用户仍为 1.0 字号，另 1 项为预期值解码器误折叠法语不换行空格。改实际用户字号后同包 24/24；修复测试预期生成器后，原主包的资源匹配及既有印尼/土耳其完整值校验 2/2。不能将普通首轮称为全绿。F-Droid 最终完整批次 34/34。

仅合成 MuMu API35/x86_64 Debug，未做本轮 R8、真机/OEM、所有页面或母语人工认证；键齐全不等于所有语气均经母语审校。已删除自有测试用户和四个包，恢复原用户/字号/旋转，停止本任务启动的 MuMu 和独立 ADB；原用户、配置和数据盘保留，清理过程见 [联合复核报告](language-issue189-autofill-review-331.md)。没有提交、推送、发布或 APK 交付。
