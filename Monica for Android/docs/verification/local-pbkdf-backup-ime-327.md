# Android 1.0.327 本地密码、备份选择与输入法验收

状态：两版构建、相关 Debug 回归、最终混淆 Release 的保留数据／恢复／输入法验收及本任务资源清理已完成。结果限于本报告列出的合成数据、模拟器和测试签名范围。

普通版与 canonical F-Droid 的本地主密码写入统一为 PBKDF2-SHA256／600000 次，移除算法切换入口。历史 PBKDF2／100000 次和 Argon2id 仍可读取；只有成功验证原密码后才沿原有事务迁移，并保留原数据密钥、记录密文、取消、锁代及修订检查。KeePass、Bitwarden 和便携备份的格式选择保留。

ZIP 导出每次先选择兼容 V1、增强 V2 或允许时的明文；默认 V1，包含受保护内容时不能选择明文。WebDAV／OneDrive 格式选择采用确认后保存，取消丢弃草稿；F-Droid 不引入 OneDrive。四条新增文案覆盖十八种资源配置。

输入法解锁 Activity 使用可调整大小的非浮动主题，认证卡片避让系统栏与键盘，内容过高时可以滚动。另修复系统字号变化时缓存的 ComposeView 仍挂在旧容器上、系统再次挂载导致 `The specified child already has a parent` 崩溃的问题；返回视图前解除旧父容器关系，保留服务原有重组器和销毁路径。

- 初始解锁被软键盘遮挡、早期填写取消／自动锁定、导出 Downloads 提供器 URI 写授权失败均保留；后续系统 Documents 提供器成功不代表所有文件提供器均已通过。
- 切字号的六次原始输入法 fatal、明确旧包负向用例，以及最终 Debug 界面和测试动画相关失败均保留。UIAutomator 输出 XML 后退出 139 的探针异常与 Monica 输入法 fatal 分开记录；只有本次新生成且可解析的 XML 才用于断言。
