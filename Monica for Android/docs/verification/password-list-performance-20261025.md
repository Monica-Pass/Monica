# 密码列表加载与滚动验证（2026-10-25）

## 范围

普通版 Android，基线提交 `f5018b64b0`。本次只调整列表观察与重复计算，不修改数据库、加密、写入、同步协议、搜索或去重规则，不切换版本号。测试复用已运行的 `Monica_Issue136_API_32`（API 32 / x86_64）。

## 改动

- 回顶按钮的滚动像素观察移入 `snapshotFlow`，保持原有显示/隐藏阈值，仅在可见性变化时通知页面。
- 延迟恢复位置的 effect 使用派生的列表数量，避免读取每帧变化的完整 `layoutInfo` 使页面重组。
- 密码页不再订阅普通滚动产生的快速定位进度；用户发起快速定位请求时仍采样当前进度。
- 分类就绪标记和分类列表共享同一条 Room 订阅。
- 全量及归档的脱敏列表在后台跳过完全相同的快照，减少重复对象复制。原始通知仍传给搜索与其他消费者，避免改变自定义字段搜索刷新行为。

## 可重复验证

`PasswordListScrollWorkTest` 使用真实的 `rememberPasswordListLazyListState` 和 300 行合成列表，记录包含该函数的页面组合次数。它检查 24 次逐步滚动、最终像素位置、回顶按钮显示、50% 快速定位、回顶，以及离开/返回后的第 80 行和 17 像素位置恢复。

`PasswordListLoadingWorkTest` 使用真实 ViewModel/Repository、独立内存 Room 数据库和委托 DAO。检查分类查询订阅数，并对 1,000 条合成记录验证重复快照、字段编辑、顺序反转、删除和空列表；活动与归档元数据必须与旧投影一致，密码字段为空，输入记录保持不变。测试不清空或写入公共模拟器已有保险库。

最终基线运行的四项设备测试完整结束：两项行为测试通过，两项性能断言按预期失败。24 次小幅滚动产生 24 次页面重组；分类查询建立 2 条订阅。旧版另有 15 项针对性的单测通过。

优化后的同组四项设备测试全部通过：

针对列表加载、滚动、分组缓存、去重、幽灵条目、分类过滤、聚合、首帧和浮动按钮的 48 项单测全部通过，无跳过。普通版与测试 APK 构建通过；实际应用冷启动返回 `Status: ok`，当前进程没有 AndroidRuntime 错误。公共模拟器原先已经运行，因此保留运行状态。
