## 实现范围

- Send 新建/编辑沿用现有条目标题、分区及“添加内容”组件。备注和访问选项按需展开，保留文本/文件内容、访问密码与日期的既有保存链。
- 同步失败按账号列出具体标题/ID、类型、阶段和分类原因，可搜索标题或 ID。不可读取标题时保留 ID；最新尝试替换旧报告，账号锁定撤销迟到写入并清除明细。报告只在内存中保存必要的标题和标识，不保存服务器错误正文或凭据。
- 密码历史支持查看、删除、清空及密码/隐藏字段变更。保留时间顺序、重复记录与未知数据；离线修改、迟到/不完整回包、丢失创建响应、重绑及锁定均保留明确操作意图。新增历史值与状态使用 MDK 加密并绑定记录、账号、修订及版本。
- 笔记、卡片、身份支持归档/取消归档及归档列表；导出/备份使用包含归档项的查询，本地恢复可取消归档。身份重复更新的地址键名先规范化，避免大小写别名导致第二次上传失败。
- 逐网址原生匹配规则保留有序重复 URL 和未知元数据，支持恢复 Default。当前自定义字段沿用原有仓库读写约定，历史保存不会额外改变其格式；实际重开编辑、搜索、自动填充规则读取、上传及冷读均覆盖。组织 viewPassword 缺省按既有契约处理，显式 false 和只读操作限制仍保留。
- Room 81→82 增加历史状态和 SecureItem 归档字段；迁移、级联及密文/记录归属校验纳入设备回归。

## 失败与修正记录

初始主版设备 55 项中 7 项失败（runner 205.633s），第二批 55 项中 5 项失败（146.851s），均保留原始本地日志。首先修正身份地址别名混合的生产问题；随后修正历史对缺省组织查看权限的误判，并恢复当前自定义字段原有存储约定，避免规则解析、同步和重开编辑受影响。新增历史权限、仓库搜索及实际规则读取回归后完整执行最终 58 项。

测试夹具还修正了旧数据库 81 断言、组织解锁/MDK 状态、SSH/组织模拟服务历史回显与旧隐藏字段断言。JVM 前序失败包括 JSON 括号、Android Base64 未启用 Robolectric、缺省序列化遗漏 cipher type。两个版本旧 KSP 缓存把 Send 测试指向旧外部路径，曾只执行 76 项；保留并隔离单测缓存后明确核对每个 XML，最终六类 87 项实际执行。早期 NoteDetailScreen 赋值和修改期间生成 DAO 不一致的编译失败亦保留。

公共镜像拒绝 root，直接 run-as 读取外部存储受挂载权限限制；改由应用自己的 Context 复制合成截图到内部文件后导出，没有绕过或更改镜像配置。
