## 改动

移除安全分析顶部 2dp 细进度条及其循环进度动画。评分卡左侧采用与附近设备同步相同的 Material3 Expressive LoadingIndicator，图形112dp、占位120dp（附近同步分别为88/96dp）。分析中使用主题主色持续变形和省略号；结束后停为静态图形并显示0–100评分，沿用原有良好/一般/需处理颜色阈值。文字根据实际填充色选择黑或白以保证对比。

现有 analysisProgress 会在泄露检查仍在等待时到达100，也可保留上次值，因此不把它显示成整体百分比，不显示虚构进度。保持原300ms分析中防闪提示逻辑。右侧汇总文字自然换行；内容区不足280dp或字号至少1.5倍时排到图形下方。中央分数按可用宽度调整字号。无障碍仅保留一个分析中进度节点，完成后撤销进度语义，读出评分说明与数字。

仅生产页面、已有JVM界面约束及新增设备测试三个Kotlin路径变化，两版逐字节一致。其余Kotlin源码与本轮开始快照一致，包括先前设置搜索和多密码修复；未改评分算法、分析ViewModel、数据库、认证、同步或附近设备同步页面。
