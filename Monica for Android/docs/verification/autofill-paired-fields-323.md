# 系统自动填充双字段修复（1.0.323）

日期：2026-10-31。普通版与 canonical F-Droid。接续 2026-10-30 中断的排查。

## 问题与证据

用户反馈酷安登录页从系统输入框提示或键盘候选选择 Monica 条目时，只能填入账号或密码之一；Bitwarden 可以同时填入。修复针对公共表单解析，不增加酷安包名、域名或版本特判。

1. `用户名、邮箱或手机号`、`Username or email` 等允许多种登录标识的标签先命中邮箱分类。在默认账号设置下，直接建议的数据构建器会拒绝把普通用户名写进邮箱字段。旧普通版 Debug `1.0.323-26103112-91` 在 API32 真实系统自动填充流程中已复现：选择密码框的建议后，测试页报告 `user=EMPTY password=OK web=READY`。这是设备填写结果，不只是字段分类断言。
2. 解析器原先把每个类名为 `android.webkit.WebView` 的节点都视为新的网页范围。若提供方将虚拟 HTML 输入框也标成这个类名，同一登录表单的账号、密码就会被拆开。该模式在结构回归中复现；本次捕获的系统 WebView 输入子节点类名实际为 null，因此不能将这个模式归因于用户的酷安版本。

前序的两个测试在 API34 均失败。本轮补充边界测试后，修前完整结构套件执行 106 项，6 项失败（3 个问题用例 × API29/34）；其余 100 项通过。真实设备负向对照执行 1 项并按预期失败，耗时 43.245 秒。

## 修改

- 标签明确列出两种以上不同登录标识并以“或”、`or`、斜线等分隔时，归为通用账号。单独的邮箱、电话、`Account email` 保留原角色；验证码、密码及显式 HTML autocomplete 语义仍优先。
- `input`、`select`、`textarea` 虚拟 HTML 控件沿用已有网页范围，不因复用 WebView 类名建立新范围。独立 WebView、不同来源及不同 HTML form 的隔离规则保持。
- 新增无网络的 WebView 登录测试页，使用普通用户名而非邮箱，覆盖从账号框和密码框触发的系统下拉与 inline 候选。实际填写由网页 input/change 事件报告，测试不提交登录。

未修改密码加密、Keystore、数据保存、锁定验证、跨库操作或应用自动填充兼容名单。没有复制参考软件的实现代码。

## 参考实现核对

本地 Bitwarden Android 参考源码的 `ViewNodeExtensions.kt` 将账号和邮箱提示统一映射为登录用户名；`AutofillParserImpl.kt` 在已有密码而缺少账号时，对密码前的未使用输入框补足账号。其 HTML 识别基于字段标签/属性，网页信息随树继承，不把每个同类名输入框单独隔离。Monica 已有弱字段、登录上下文及作用域逻辑，本次只修复已复现的分类和范围问题，不宣称完整达到 Bitwarden 所有支持范围。

用户提供的 `密码键盘分析.zip` 中，`apktool_out/res/xml/auto_filler.xml` 及 `xml-v22/auto_filler.xml` 确有 `com.coolapk.market` 的 `compatibility-package` 配置；这表示请求 Android 兼容通道，并不能证明存在酷安专用双字段算法。`PassStore_1.2.5_逆向分析与代码.zip` 的首轮代码检索没有发现对应酷安特判。压缩包仅作为文本/资源参考，未执行内含程序。

### 中间失败与验证边界

前次普通版 13 项设备运行有 1 项失败（205.043 秒）：密码框获得焦点且 Gboard 已显示，但 20 秒内没有观察到 inline 候选；另外 12 项通过。接续冷启动后的首次单项运行则在 `open()` 等待测试 Activity 的可访问性窗口时失败（25.285 秒），尚未进入字段点击步骤。这两次失败发生在不同阶段，不能认定同因。

相同 APK／测试包在后续单项及两版完整套件中通过，没有为取得通过修改生产逻辑、延长等待、去掉输入法窗口断言或放宽表单隔离。先前 inline 候选偶发缺失的原因仍未确认，不能据最终通过宣称所有键盘／系统候选时序问题均已解决。原始失败日志与合成截图保留在本地 `.codex-tmp/autofill-paired-323/`。

## 限制与清理

酷安官方下载的 16.7.0 APK 在公共 x86_64 模拟器的 ARM64 转译环境中启动失败，异常为其 `com.netease.nis.wrapper.MyJni.load` 的 `UnsatisfiedLinkError`。没有更改或绕过其加固程序；本轮无法声称已经完成酷安应用内、用户真机或厂商 ROM 的验证。

公开登录页面的字段模式用于本地合成表单，真实 Android AssistStructure 的元数据捕获确认同时包含账号和密码。没有使用真实账户或提交登录。截图、安装包、参考压缩包及诊断探针只保留在本地临时目录，不入库。

复用公共 `Monica_Issue136_API_32` 与前序任务创建的专用 Android 用户 14（`Monica_Autofill_Paired323`）。接续时公共 AVD 已停止，使用原配置与数据盘启动。验证完成后核对酷安与 `local.monica.pairedprobe` 只安装在用户 14，将它们从该用户卸载；切回用户 0，移除专用用户 14 及其合成库、设置和失败截图。用户 0、10、11、12 均保留，未清理主用户数据。已停止本次启动的公共 AVD，保留配置和数据盘供后续复用。

两版中英文发行说明及 F-Droid fastlane `30.txt` 已同步。版本仍为 1.0.323 未发布；本次没有提交、推送、创建 Release／标签或交付安装包。独立启动诊断等既有未提交改动保留。
