## 设计检查

本机 M3E Canvas 导入了 20 个页面状态、129 个节点，已实际打开首页、编辑详情、恢复预览并点击页面链接。静态检查所有 action 目标均能解析到一个页面。固定 Canvas 是可编辑流程草图；网页原型进一步实现了筛选、字段选择、主题、字号和模拟结果状态。

浏览器中实际走过以下合成交互：

- 首页 → 多账号编辑 → 恢复预览，取消一个字段后确认按钮和涉及账号数变为 1；全不选时按钮禁用。
- 确认字段恢复 → 完成结果 → 回到时间线；恢复作为新的操作显示。
- 搜索“验证器”后只出现匹配项目。
- 删除详情 → 预览 → 取消返回详情，再次预览 → 确认 → 验证器已恢复。
- 后续修改冲突 → 另存完整历史副本预览 → 确认，结果说明原项目保留。
- 批量移动 → 4 项恢复预览 → 完成，明确另 2 项未执行。
- 同步失败 → 失败项目 → 模拟重试完成 → 同步列表显示 3 项上传、1 项接收及重试成功。
- 零变更后台检查展开后解释检查次数与项目数不同。
- 先恢复编辑再恢复删除，再打开编辑的恢复记录，仍显示对应的 2 处修改结果。
- 旧版记录展示“未记录删除方式和恢复数据”，锁定场景移除详情内容。
- 320dp、双倍字号、深色编辑详情已查看；DOM 尺寸检查没有横向溢出，内容纵向滚动。
- 标准字号浅色首页、编辑详情、删除详情和稳定 Canvas 恢复预览截图已查看；截图只留本地忽略目录。

检查中修正了网页演示的选择范围计数、不同事件恢复结果关联，以及重试完成后同步列表仍显示失败的问题。场景选择的首次语义标签定位未匹配，改用已观察到的控件 ID；这属于原型驱动定位，不是产品故障。首次 Canvas 截图捕获了过渡中间帧，之后另存并检查稳定页面，未把中间帧当作最终验收。

## 限制

- 所有确认、恢复、上传、解锁均为网页内存状态模拟；未接触真实项目、密码库或远端服务。
- 未运行 Android 构建、MuMu/AVD、Release 升级、TalkBack 或真实 provider 测试。
- 网页原型不证明事务、加密、锁代、修订冲突或永久删除安全性。具体生产验收要求在设计文档中列出。
- Canvas 20 个状态不等于 20 个 Android 页面；部分是用于表达分支的简化流程页。没有逐页宣称 Android 像素一致。
- 审查的 15 个相关源文件，普通版与 F-Droid 14 个字节一致，另 1 个仅换行差异；设计过程中这些源文件未修改。
