# Bitwarden 当前兼容范围（1.0.325）

按58项原审计ID更新状态；分类不是完成率，各项存在重叠。本轮按已确认范围补齐个人账号和自托管能力；组织／集合、高级认证与企业安全继续暂缓，待实现项不计为完成。

此前设置／个人库批次两版各159项JVM、77项常规API32方法、2个独立进程阶段及1个补充真实草稿页面入口通过，共80个不同设备方法。补充入口测试单独重建测试包，主APK未变。使用合成账号，真实官方账号103条记录属于先前版本的限定证据；本轮没有重新访问真实账号。

详见 bitwarden-settings-completion-325.md 及同名前缀结果；历史能力按原报告的冻结版本使用。本表不表示完整官方客户端兼容。

账号基础补充：两版各62项JVM及28个不同API32设备方法通过；实际窗口绘制和截图另行核对。只将AUTH_A03与AUTH_A12从待实现改为限定验收，详见 bitwarden-account-basics-325.md；不同批次不机械合计用例数。

自托管配置补充：两版各183项JVM及120个不同API32设备方法通过，各954条实际APK文案核对；只将AUTH_A18从部分支持改为限定验收。该批次结束时24项沿用或限定验收、34项待实现/部分支持/上游实验，详见 bitwarden-server-configuration-325.md。

个人可靠性补充：两版各247项JVM及2个显式附件进程阶段通过，164个不同API32常规方法取得通过结果，各2052条实际APK文案核对。两版完整批次各163/164，文件选择器观察失败后同包单项各1/1；FD窗口记录确认失败时实际选择器已打开，未将原失败计为通过，具体批次见验证报告。当前29项沿用/限定验收，另19项待实现、7项部分支持、3项上游实验；分类不等于完成率。组织/高级认证/用户密钥轮换保持暂缓，详见 bitwarden-personal-reliability-325.md。
