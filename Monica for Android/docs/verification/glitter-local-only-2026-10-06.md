# Glitter 本地专用验证（2026-10-06）

> 历史记录：后续产品约定已调整为 Android 与 Monica CLI 暂不接入 Glitter，MDBX 引擎保留格式能力。下文记录此前本地-only 实现的测试事实，不代表当前客户端功能；CLI 当前仅保留只读识别并拒绝创建、打开、管理和同步，不再推荐本地 CLI 接入。

## 最终产品约定

- Glitter 仅用于本地数据库：主密码＋至少 32 字节的密钥文件，不要求指纹、硬件绑定或专属授权票据。
- OneDrive / WebDAV 不允许创建、接入或同步 Glitter，后台自动同步也不可绕过。F-Droid 仅有 WebDAV，不包含 OneDrive。
- 保留内部存储、外部加密文件写回、手动加密备份及换机后本地导入。第三方文件管理器自行上传文件不属于 Monica 内置云功能。
- 创建/打开表单遵循应用截图设置；敏感内容页保留保护。内容不复制到聚合列表或后台自动填充。
- 固定 Argon2id 512 MiB / 10 / 4；内存不足明确拒绝，不静默降低强度。

## 拒绝边界

1. 远程创建界面只提供 Sky / Multi / Power；提交校验与 ViewModel 也拒绝 Glitter。
2. Worker 和数据能力先拒绝已知 Glitter / 旧硬件凭据；远程会话再检查原生数据库内的实际策略，避免旧 Room 模式标签伪装成 Sky。
3. 已知 Glitter 在连接测试、上传、下载、登记同步状态之前拒绝；每个原生同步批次再次检查策略。
4. 未知远程文件必须先下载到新建的应用私有暂存位置以识别。原生验证判定为 Glitter 后，不登记数据库或云源，不下载附件、不写云端；清理暂存文件及 SQLite sidecar。下载失败也清理，保留原本地库和调用者密钥。
5. 本地读写没有被远程门禁禁用；手动加密备份可在另一个设备标识下使用相同密码和密钥打开。

## 性能边界

桌面 3,000 条记录 × 3 轮轮换，复测无编译器/AVD运行，但有其他桌面负载；Power 设备能力为模拟，不代表手机耗时。

| 中位数 | Sky | Power | Glitter |
| --- | ---: | ---: | ---: |
| 完整解锁 | 9 ms | 1,272 ms | 2,817 ms |
| 首次完整浏览 | 68.87 ms | 77.69 ms | 81.75 ms |
| 热浏览 P50 | 69.62 ms | 73.53 ms | 1.60 ms |
| 写入 3,000 条 | 1,288 ms | 1,343 ms | 1,442 ms |

热浏览约快 44–46 倍，但不能宣称解锁、首次浏览或写入全面更快。缓存计账约 3.51 MiB，不等于整个进程内存。两次基准共 18 个场景的读写/敏感数据授权断言通过。

## 未混淆的历史结果和限制

- 原生 portable 阶段 997 项通过、1 项原有忽略，真机 JNI 2 项和双版本 API 32 JNI 各 2 项通过。它们是原生基础证据，不替代本轮 local-only 验证。
- 早期真实 OneDrive：Sky 基线通过；Glitter 实验在接收增量时失败，并非同步成功。随后用户明确改为本地专用，未继续 Glitter 云功能；合成云目录删除、设备设置恢复均有记录。
- Android 早期全量 JVM 有既有多语言和界面源码断言失败，不能宣称全项目全绿；本轮限定 MDBX 的回归全绿。
- 原生 strict clippy 存在既有 lint 债务；普通 clippy/fmt 通过。自动生成的 UniFFI binding 保留生成器空白，整个仓库 diff whitespace 检查会报告这些行；手写 app 代码/发行说明专项 diff 检查通过。
- 未提交、发布或额外复制 APK；保留用户数据、版本号和公共 AVD 数据盘。

设备收尾：Pixel 6 上删除了本任务合成的旧密钥文件与诊断 XML，主机对应临时密钥已删除；卸载本任务新增的独立原生引擎测试包，保留 Monica 用户应用及数据。公共 AVD 已停止，内存大小仅用临时启动参数，未改保存配置。全部 runner 的应用用户/屏幕超时恢复检查为 true。
