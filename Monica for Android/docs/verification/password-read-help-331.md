# 不可读密码点击说明（未发布 1.0.331）

## 行为

密码详情中的不可读区域现在可以点击，说明图标取代无效的复制图标。Material 3 对话框展示此次读取能够确认的错误类别：设备认证未完成、系统报告密钥失效、密钥无法取出、加密校验失败、原因未知。详情只保留枚举，不保留异常对象、异常原文、密码或密钥，也不额外扫描环境或重试解密。

本地密码在非设备认证错误时提供条件建议：若曾更改 OMK（OhMyKeymint）、Keybox 或系统密钥环境，可尝试还原为此前能读取时的配置，再重启设备并解锁 Monica。文案明确尚未确认这是原因，也不能保证恢复；提醒原数据保留，不要清除应用数据或卸载。无法取出密钥不等于已证实密钥丢失；GCM 校验失败不区分密钥不匹配与数据损坏。

Bitwarden 继续显示原有来源说明及重新同步按钮；KeePass/MDBX 提示检查所属数据库，归属冲突显示既有冲突说明。正常和空密码不出现错误入口。单密码、多密码及账号组均传递各自原因；弹窗正文滚动、固定关闭按钮，支持系统返回、锁定及后台关闭。全部 21 资源配置各新增 10 条文案，两版同步。

仅增加详情显示与错误分类传递，既有密码读取、加密、KDF、认证、密钥恢复及数据存储行为未改变。此前用户故障的根因仍未定位，本次说明不代表旧密码已恢复。
