# 当前原库合并与面包屑状态 1.0.323

## 用户要求与代码依据

此前将文件状态单独放在路径上方、把“合并数据”接到选择其他数据库的 sheet，偏离用户要求。
已只读核对本地官方 KeePassDX 4.5.6 源码参考：`GroupActivity.menu_merge_database` → `DatabaseLockActivity.mergeDatabase()` → `DatabaseTaskProvider.startDatabaseMerge()` → `MergeDatabaseRunnable`。
其未提供 from URI 时读取 `database.fileUri`，未提供新凭据时复用当前主密钥，再按 UUID 合并和保存；“从其他文件合并”是独立入口。此处参考调用语义，没有复制其 GPL 实现。

## 修改

- 密码页、密码库页复用各自路径所在的同一区域显示文件状态；READY 不显示提示，移除路径上方的独立状态条。
- 普通保存/加载/合并成功 3 秒后恢复路径；错误和同时间内容冲突提供关闭入口。每次通知具有独立身份，旧计时不能清除新操作结果。
- 沿用单层 260ms 高度过渡，列表随容器移动；锁定立即移除路径和状态内容。截图发现旧路径固定 36dp 会裁切 1.5 倍字号，现改为 36dp 最小高度、由文字撑开，内层不再强占固定高度。
- 菜单直接合并当前已打开库的内存版本与重新读取的同一个文件，使用原解锁凭据，不再选择文件或输入密码。
- 本地/SAF 原文件继续验证写入与恢复副本。源配置、锁定轮次、内存实例和密文修订在操作边界重新核对；坏文件/只读/失去会话时不覆盖来源。
- 云端库读取已绑定的真实远端，检查读取前后版本并以该版本条件写入；没有版本条件则拒绝操作。成功验证后推进工作副本、同步基线和已包含的待处理队列。远端失败不假报合并成功。
- 复用现有按 UUID 的合并器与原 13 语言资源；跨库导入/复制/移动入口保持各自语义。
