# 1.0.331 触觉兼容与强度设置验证

2026-11-25，普通版与 canonical F-Droid，未发布。针对“功能正常，但点击没有震动”的反馈，开关及滑块在请求期间启用宿主 View 的触觉反馈，随后恢复原状态；View 拒绝请求时，仅尝试一次标记为 TOUCH 的 Vibrator 兼容输出。系统或应用关闭、页面不可见/脱离时不补震，成功接受的请求不重复输出。不能据此断言反馈者手机的具体根因已经复现。

「设置 → 功能拓展 → 触觉反馈」加入 0 关闭、1 轻、2 强，默认 1；原页面调整入口使用相同控制。滑动换档立即预览新档，松手保存，关闭后仍能拖到非零档重新开启，并提供测试震动按钮。系统关闭或无可用输出时给出相应说明，提示区域按减少动画设置平滑变化。强度随偏好保存，进入配置快照与备份映射，缺少字段的旧设置默认 1。普通按钮及其他既有反馈类型没有全量重新接线，输入法原反馈逻辑保持原路径。

## 来源与许可

参考 [T8RIN/ImageToolbox](https://github.com/T8RIN/ImageToolbox) 提交 ab763ce76effd13ae3b8c7cfea37835eb9e0f8b9 的 EnhancedHapticFeedback.kt 和 VibrationStrengthSettingItem.kt，沿用 1/CONTEXT_CLICK、2/LONG_PRESS 的档位对应；本轮触觉兼容实现独立编写，没有复制其忽略系统设置的行为。上一轮滑块改编的作者声明、完整 Apache-2.0 许可证继续随两版 APK 分发，最终包内文件哈希与源码一致，README 已补充强度设置参考来源。

设备覆盖宿主默认禁用反馈、切换强度、关闭后重新开启、单次预览、系统关闭提示、偏好提交和恢复、设置搜索全语言与真实页面锚点、功能拓展保存和返回、280dp/1.5 字号深色控件，以及开关整行/禁用/取消、滑块正反拖动/RTL/无障碍/48dp布局/松手提交/DPI重置、生成器 8 项及输入法按键 2 项既有回归。配置测试实际读写 DataStore 与 PageAdjustmentSettingsSnapshot；WebDAV 配置序列化映射经编译和源码核对，本轮未重新执行完整云端备份往返。

Android vibration service 日志包含本轮包的 View 请求 ignored_unsupported，以及 TOUCH/TICK、reason=null、finished 的兼容输出记录。部分输出来自合成拒绝条件，日志证明请求进入 Android 服务，不能证明物理马达响应、强度或用户手机与 ImageToolbox 手感一致。

实际查看两版功能拓展页面及深色大字号控件截图，滑块、数值和测试按钮可达。深色截图为独立控件宿主，顶部的测试开关不代表触觉总开关；不是整页深色验收。普通首轮截图被 MuMu 广告遮挡，排除出视觉验收；仅停止自建用户中的广告进程，后续截图无遮挡。草图与截图只保存在忽略的 docs/design，不入库。

## 保留的失败

普通首轮设置测试在写入后立即读取 shareIn(replay=1) 的旧缓存，18 项中 1 项失败。修正测试为直接导出已提交的 DataStore 值，再等待 UI flow 出现预期状态，保持原断言目的。第二轮新增实际 Extensions 页面测试，保存与预览已完成，最后返回步骤错用 R.string.back；页面实际使用 R.string.go_back。仅修正测试引用，新类 6 项通过。没有为通过测试修改生产行为、删除断言或扩大原超时，原失败日志保留。

F-Droid 英文 fastlane 初次检查因末尾换行使总长超过 500 字符失败，缩短文字后元数据检查及 6 项脚本单测通过。最初来源审计将未纳入修改前 app/src 清单的 kotpass/Gradle 误计为新改动，已按清单范围修正，完整构建快照仍包含并校验这些文件。

## 一致性与范围

每版本轮 app/src 改动 35 个路径：12 个既有文件与 23 个新文件，包含 19 份文案文件、每版 95 个文案值。共享路径 32 份字节一致，MainActivity、Setting、WebDavHelper 保留原平台差异，但本轮增量一致。全部 app/src、kotpass/src 和 app/build.gradle 与最终测试构建快照一致。新增强度文案补齐当前支持语言；本轮未做逐个语言页面视觉验收或母语审校。

仅 API35/x86_64/Debug/合成数据，未做物理真机、OEM、Android26–28回退分支、R8/Release或正式包覆盖升级验证，也未操作用户密码库。View/服务接受请求仍可能因设备策略不产生可感震动，测试按钮不把“请求已提交”描述为物理震动成功。

清理只移除自建测试用户及四个独立测试包，恢复原用户；原用户集合、正式 Monica 安装元数据和系统密度核对保留，专用 ADB 已停止。MuMu 实例继续运行，进程仍与任务开始时一致。没有提交、推送、发布或交付安装包。发行说明未重新添加验证报告或操作指南链接。
