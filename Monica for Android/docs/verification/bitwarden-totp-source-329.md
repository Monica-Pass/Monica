# Bitwarden 验证码来源筛选修复（329，未发布）

2026-11-18，核对 [issue #185](https://github.com/Monica-Pass/Monica/issues/185) 的正文、截图及评论。截图显示添加验证器时选择 Bitwarden 账号根目录，随后同名验证码出现在 Monica 来源。发现并复现了吻合的程序缺陷，不能仅将反馈归为使用问题；截图本身不足以确认该用户具体条目的实际写入位置。

`TotpViewModel.mergeStoredAndVirtualTotps` 为密码的 `authenticatorKey` 建立临时验证码显示项时，只保留 vault/folder，没有保留 cipher ID、revision 和 localModified。无文件夹时显示项失去具体 Bitwarden 绑定证据，被既有 ownership 判定为本地；有文件夹时文件夹信息掩盖了归属错误。修复仅在原显示投影中带回这三个来源字段，未改变全局归属规则、数据库、加密、迁移、同步或保存选择，不新增强制 Bitwarden 功能。已有新建默认值沿用页面所选 Bitwarden 账号及文件夹。
