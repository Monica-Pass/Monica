# Move/copy folder scope — 1.0.325 (unreleased)

The shared destination sheet now limits Monica categories to the same local ownership predicate used by the main folder menu. MDBX-linked category rows are no longer offered as local targets, including links to unavailable databases. Valid empty categories, same-name categories, and Bitwarden-linked local categories remain. No category rows or user database contents are deleted or merged. The screenshots do not establish that the user's extra folders came from old empty databases.

KeePass, MDBX and Bitwarden folder collection state is keyed to the selected database. Before that source's first emission, the sheet cannot display the previous source's folder IDs under the new database ID. Selection must remain present among the current targets; an empty allowed-source list does not fall back to Monica. Dismissal, selection/action changes and invalidated targets revoke deferred confirmation. Each deferred attempt is consumed once, retains the original source callback and rechecks current targets, action permission and KeePass write availability. Actual repository authentication, revision and write protections are unchanged.
