# 密码库概览搜索入场动效（1.0.328，未发布）

2026-11-17，普通版与 canonical F-Droid 共用实现。打开概览搜索后，首批结果就绪时整组结果从下方 24dp 上移并淡入，标准动画倍率下 220ms 减速落位。查询更新、滚动或已完成入场后的结果刷新不会重新播放；重新打开搜索才重新入场。

`VaultOverviewSearch.kt` 使用进程内 Compose Animatable 与 graphicsLayer，只在图层回调读取逐帧进度；不让索引准备、排序或列表数据计算随帧重复执行。准备阶段保留加载提示，结果延迟到达仍有入场。应用减少动画直接显示；系统时长倍率由 Compose 动画上下文处理。关闭搜索和锁库沿原有条件立即移除组成，不保留退出中的敏感列表。`VaultOverviewScreen.kt` 仅向搜索结果传递减少动画参数。无数据库、认证、存储或索引算法变更。
