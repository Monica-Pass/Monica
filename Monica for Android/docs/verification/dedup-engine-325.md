# 去重引擎 1.0.325 实现与验证

日期：2026-11-06。普通版 code12、canonical F-Droid code32，均未发布。验证仅使用公共 API32/x86_64 虚拟机和本任务创建的合成数据；未打开、移动或清理用户真实数据库。原有 KeePass 切库和全部视图改动保留。本轮没有提交、推送、标签、发布或 APK 交付。

## 已实现行为

单库以完整项目结构证明包含：A={1,2,3}、B={1,2}、C={2,3,4} 时仅 B 可指向 A；不能用多个项目的并集或待清理项目组成删除链。账号与密码对应、普通/隐藏/重复字段及保护位、内容顺序、“添加内容”块、钱包扩展、历史、附件、已知原生行为和引用均参与证明。无法读取、未知结构、缺失成员、需重写引用、超出工作上限时保留。当前原生审计时间存入恢复包，但并非所有当前创建/访问时间都必须相等才匹配；过期语义和历史内容继续核对。

| 来源 | 单库分析和清理 | 跨库合并来源 |
| --- | --- | --- |
| Monica 本地 | 完整 Room 读取；先验证加密恢复点，再与软删除同事务提交 | 复制完整可表达的当前项目；需重写引用、未知字段或未迁移历史的项目保留 |
| 内部 KeePass KDBX 4.1 | 仅满足完整性、可写、回收站开启和内部来源条件时清理/恢复 | 从新鲜原生文件读取；不完整字段、历史、原生 Passkey/模板等无法完整迁移时保留 |
| 外部/远端/其他 KeePass | 不开放本路径批量清理 | 同样要求完整原生证明；不满足则保留 |
| Bitwarden | 原生 cipher 分析，清理关闭：服务端无审阅修订条件的删除接口 | 支持可完整表达的类型；组织、原生凭据、历史、链接字段等不兼容内容保留 |
| MDBX | 原生 FFI 读取，但历史/策略快照和恢复协议不完整，所有项目保留且无可清理候选 | 整库保留，单独显示真实库名，不用 Room 镜像冒充完整原生内容 |

跨库目标仍为 Monica 本地或受支持的 Rust MDBX。不同密码/扩展内容保留独立变体，原来源不删除。审阅计划一次使用，锁定、授权或已审阅数据变化会拒绝旧计划。所有 Passkey 及关联项目均被排除，包括原生 KeePass Passkey 的登录投影。独立验证器的 boundPasswordId 等内层引用、未知 schema/资产及 Room 密码历史/时间线内容不能安全迁移时保留。

MDBX 目标明确提示新增独立副本，不仅凭陈旧 Room 镜像跳过数据。密码/安全项目采用新的副本身份，原生提交采用 create-only 检查及事务内普通 INSERT；现存、回收、已删目录中的对象和永久清除回执均不能被复用。去重引擎不再写入 Passkey；底层新增接口仍验证固定凭据身份冲突时拒绝写入。碰撞失败不会通过补偿删除原件。原生提交后、跨存储确认前失败可能留下新增副本；不能据此宣称跨存储原子回滚或任意外部编辑的完整 CAS 保证。克隆后的自定义字段若仍含 Monica 密文，整个项目保留，避免新库依赖来源应用密钥；因此部分需要重建 ID 的内容块/钱包不能复制到 MDBX。普通及保护字段、可独立表示的标准字段和附件另有真实原生正向验证，完整复杂内容到 Monica 本地的正向验证仍保留。

## 恢复与 UI

最终按用户明确要求：独立 Passkey、包含或绑定 Passkey 的完整项目不参与单库去重或跨库复制，不存在风险确认后强行处理的入口。明确结构化 Passkey/FIDO 字段和已知嵌套标签也保守保留，不扫描任意备注猜测密钥。Passkey 清单弹窗只告知实际保留对象，确认仅继续审阅其他项目，原凭据和绑定不变。每次进入模式先显示风险与范围说明，明确自动判断可能误判或遗漏、执行前核对并保留独立备份、后续修改可能影响恢复，以及本机恢复点不能替代备份。确认前不能启动分析，取消返回；不永久记住不再提示。分析确认与最终清理/复制确认分别进行。

Room 从84迁移到85，恢复记录独立于原项目的级联删除。Local 恢复保留附件密文副本；仅当原 ID 不存在或当前记录等于本批次精确墓碑时恢复，不覆盖活动记录或后来编辑。原生 KDBX 先持久化加密包，再对更新后的整个数据库做编解码等价检查，以同目录 staging、源 hash、最后授权检查、原子替换和 fsync 提交，不退回截断覆盖。原 UUID 永久删除后按批次派生稳定新 UUID 恢复副本，保留墓碑，重试不重复创建。

原生恢复包明文上限32MiB、密文64MiB，Room只存小型加密manifest；Local单批恢复payload上限512KiB，附件源blob上限512MiB，超限停止。恢复点依赖应用密钥和本机数据，不能冒充可脱离应用/设备的异地备份。

单库页面采用 Monica Material 3 主题：可见分组容器、48dp次操作、紧凑统计、候选→保留关系卡片，普通字号同排底栏，大字号纵排且不压小字体。默认不选中，审阅和确认保留。跨库整库保留列表不混入项目计数，MDBX独立副本提示在页面和最终确认均可见。每版导出21张最终截图，检查全部联系表及普通字号入口原图，覆盖中文浅色/深色/1.6字号、风险/Passkey弹窗及分析、确认、清理、恢复组件；截图只留忽略目录，不入库。大字入口同时保存首屏和滚动到底的画面，顶部被裁半行的后者不冒充首屏。深色组件测试的系统栏由测试Activity控制，验证不等于完整MainActivity导航或所有OEM系统栏验收。

## 失败保留与修正

早期main01参数拆分、main02编译、main03/04/05并行输入或测试API、main06联合JVM夹具失败均保留。main06已组装包只用于诊断；main07完整构建及后续main09/main11/main13均有独立包与回执。main08、main10为测试编译错误；main12会话中断，无result，不能算成功。main14主包完成后测试编译发现suspend辅助函数及必填website遗漏，修正仅限夹具。详细每轮结果及失败方法见result.json的earlierResults，本地原始日志继续保留。

首轮设备确实暴露原生审计误拒空可选UUID、默认根组行为兼容、MDBX历史分页上限问题，已经收窄修复并保留负向检查。早期旧夹具缺真实会话、MDK、原生来源或违反一次审阅契约，分别修正前提并保留目标/源数据断言。性能计数曾把848主键核验误算全库扫描；仅修计数分类并检查真实PRIMARY KEY执行计划，未移除核验或抬高阈值。main11的4个Matrix失败先修真实历史准备；main13仍4失败进一步证实原生Passkey双投影能力门控缺口，保留原期待并修生产门控，另补内层引用、历史、MDBX原生防覆盖边界。main15仍有3项失败：独立OTP解析先规范化内层密文造成MAC失败，修为先解密并按项目隔离身份错误；目录夹具改为先软删除原生对象再删目录；卡面夹具为每个owner配置独立附件并另保留缺附件负向，不删除原复制断言。后续按用户最终要求排除全部Passkey及绑定项目，新增前置风险/范围说明；这些变动均以后续最终回执为准。

main16在生产 Kotlin coroutine CFG 编译阶段发生 StackOverflowError，未执行设备测试。仅提取 scanPlan 内三个纯计算段到普通非 inline、非 suspend 私有辅助方法，359行减至210行；逆向代回后整个文件内容一致，未增加编译栈或关闭安全检查。main17完整构建及121JVM通过，随后main18仅更新18语言风险措辞，完整构建54.318s、121JVM通过。main18设备144方法中143通过；唯一失败是旧测试仍期待复杂内容块复制到MDBX，但新字段密文保护已正确保留该项目。保留原完整复杂夹具和Monica目标正向，新增MDBX全保留/源目标原字节不变断言及可独立保存字段和附件的MDBX正向对照，生产能力门控不变。最终回执使用修正后的测试，原main18失败保留。入口额外截图在原用例内补充首屏和普通字号，不新增重复方法，也不改变生产行为。
