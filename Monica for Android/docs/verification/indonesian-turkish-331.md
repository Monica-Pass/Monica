# 印尼语与土耳其语验证（普通版，未发布 1.0.331）

新增 Bahasa Indonesia 和 Türkçe，分别使用 `id-ID` 与 `tr-TR`；印尼语兼容 Android 的 `id` / `in` 代码。每种语言 130 个 XML，覆盖当前全部 7,351 个可翻译资源键，包括字符串、数组及复数。旧语言枚举顺序保留，语言选择、首次设置、启动缓存和保留消息解析接入两种语言。

导航短标签复用现有单行 10–12sp 自适应规则并遵循系统字号，适配 320dp 可选导航和 360dp 默认导航。统一密码、通行密钥、恢复限制等用语，修正截图审查发现的连接符词序及同类设置分组、帮助路径文案。机器翻译初稿经过术语与关键恢复条件定向校对，但未经过母语者逐条审校。

## 失败记录与边界

最初翻译占位符丢失/批次异常及 XML `utf8` 声明错误保留在本地，校正后资源契约通过。`main-full01` 构建期间资源和测试仍变化，其 `sourceUnchanged=false`，不作为最终证据。普通版 `main-final03/04` 本地 init 脚本语法/API 错误、F-Droid `fd-full01/fd-final03` 驱动未完整执行记录保留，不计通过；最终构建未跳过必要任务。

普通版首轮 27/27 被 MuMu 商店广告浮层遮挡，仅计组件/内部断言。关闭浮层后 `main-unobscured02` 为 11/14；调整夹具在 Activity 启动前写语言、使用本地化 Activity，并补实际字号与内容根就绪检查。`main-final-device03` 37/38、`main-final-device04` 36/38，仍出现 ActivityScenario 辅助 Activity 转屏重建/无 Compose 层次错误。日志确认模拟器横竖屏反复切换，随后只将测试环境固定竖屏，原断言保留；两版最终 38/38。此结果不代表通用转屏竞态已修复。接管后进一步修正文案并重新执行上述完整最终批次，早期失败未被覆盖。
