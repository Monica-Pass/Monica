# 手机热点同步验证（1.0.323，未发布）

日期：2026-10-29。

## 改动与原因

原生 TCP 已监听全部本地接口，邀请会包含可用的私网 IPv4。原来自动同步只允许系统 NSD 判定在线的已配对设备进入发现及监听；在热点 AP 不参与 NSD 或组播不可用时，双方可能一直等待。

补充前台 UDP 在线通知（53319 端口），每 15 秒最多发送到 32 个已知地址、实际 Wi-Fi 网关与接口定向广播。只接纳已配对设备的提示，提示 45 秒后失效；锁定或后台时关闭套接字。回复源地址进入本轮发现候选，正式保存地址仍发生在经过 Noise 身份验证的同步完成之后。

原生发现（53318 端口）补充实际接口的定向广播，保留 2 秒发现窗口、私网限制与候选数量限制。没有猜测或遍历网段，没有使用全网广播地址。

Android 为目标所在 Wi-Fi 子网绑定同步套接字，避免无互联网热点的本地请求走蜂窝默认网络；不修改整个进程的网络绑定，有活跃 VPN 时保留其路由。网络地址或句柄切换后重启空闲监听与在线发现；已经进入传输或应用的会话仍由原有取消、超时和原子写入机制收尾。

回归还发现上一轮完成时可能清除其收尾期间排队的新手动请求。传输现在记录启动时的请求编号，只结束本轮对应的请求。

网络变化时仅重启普通同步的空闲连接，保留显示配对二维码所依赖的全接口监听。补充真实协调器和 JNI 回归，修复前可复现监听已被删除但页面仍显示配对状态的问题。

## 验证

- 基线：禁用系统 NSD 后，旧自动协调器未建立同步，设备测试 1 项失败（预期）。
- 初次设备回归：15 项中 13 项通过，热点在线通知及无 NSD 的两个连接角色通过；手动请求排队问题与未回应合成删除确认的旧测试夹具未通过，已针对性修正。
- 最终普通版主程序及测试包构建成功（10m 21s）；最终完整设备回归 **20 项通过、0 项失败、0 项跳过**（225.66s）。
- 最终 F-Droid 主程序及测试包构建成功（移除诊断后的构建 2m 48s）；最终完整设备回归 **20 项通过、0 项失败、0 项跳过**（228.606s）。
- 两版最终回归覆盖热点在线发现、无 NSD 的两种角色、Wi-Fi Network 绑定、后台／重开、手动请求排队、配对监听保持，以及 610 条密码加丰富卡包／Passkey／Steam 的 625 条记录组合。批量测试验证大附件、字段、回收站、计数器限制、两轮同步、关闭自动后手动同步，以及合成数据的删除确认。
- 原生传输：普通版与 F-Droid 各 42 项、扩展 37 项通过，包括关闭组播后的真实定向广播发现、身份拒绝、加密内容与接收模式限制。
- 最终扩展原生宿主 Release 构建通过；首次与 Android 构建重叠时因宿主内存不足退出，单独串行重试成功。

F-Droid 首次最终设备回归中 12 项因 JNI `native_unavailable` 失败：其 JNI 构建未指定 API，cargo-ndk 默认 API 21，链接产物引用 API 23 新增的 `android_setsocknetwork` 却缺少 `libandroid.so` 依赖。构建目标已明确为应用最低 API 26，重新链接后两版 arm64-v8a、armeabi-v7a、x86_64 的 ELF 依赖检查均包含 `libandroid.so`。Cargo 曾复用旧 API 的最终 crate 产物，仅移除该 JNI crate 的可重建目标产物后重新链接；未清理虚拟机或应用数据。F-Droid 修正后主包及测试包构建通过（41s），设备结果另列。

此前两版批量测试曾在 `confirming` 阶段报告 `connection_failed`，独立轮询和恢复生产 500ms 周期后仍复现。后续公共 AVD 的系统进程因设置系统属性失败而崩溃，ActivityManager 不可用，诊断 instrumentation 无法启动。保留日志后仅重启公共 AVD，未清理数据或数据盘。恢复后 F-Droid 诊断版本单项通过（181.512s），普通版无诊断版本单项通过（91.109s）；随后移除全部临时 socket 诊断并完成上列两版完整 20 项回归。数据处理、加密、会话保护和传输期限未因此修改。不能仅凭这些现象确定早期每次连接失败的根因，也不能将 625/625 的进度提示视为整轮确认成功；最终结果以完整断言与测试退出为准。

设备测试复用公共 API-32 AVD，使用内存数据库、独立偏好名与合成密码、卡包及 Steam 数据。测试夹具明确回应合成数据的删除确认；批量同步夹具用独立协程模拟用户活动，并按生产 500ms 周期独立驱动两端。临时阶段日志已移除。生产删除确认、会话超时和自动锁定设置保持原样。未清理应用数据或重建密钥，未发布、推送或交付安装包。

## 验证范围

无 NSD / 无组播场景通过真实 UDP 与 JNI 传输注入复现，并覆盖源地址更新、后台退出、重开、关闭自动后手动同步。Wi-Fi 绑定测试使用 Android 实际 Network 句柄；错误网络句柄应停止发现而不是切换网络。

当前没有两台实体手机的热点无线链路实测，不把虚拟机与宿主的 socket 验证等同于所有厂商热点兼容。热点必须允许两端之间的本地通信。使用时先连接热点，再在两端打开并解锁 Monica，沿用现有配对与同步入口。

代码、两版最终构建、完整设备回归和验证记录已收尾。早期失败日志继续保留，不据此承诺真机速度或所有热点型号的兼容性。
