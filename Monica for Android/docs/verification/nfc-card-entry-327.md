## 功能与边界

MainActivity 接入前台 NFC 与 `TECH_DISCOVERED`／IsoDep 入口；原 FIDO 专用 Activity 继续独立管理自己的读卡会话。未授权或锁定时立即移除 Intent 中的 Tag、ID 和 NDEF extras，仅提示解锁后重新贴卡，不保留卡片等待认证。暖启动先等待已恢复的编辑器注册，Tag 最多暂存3秒；解析结果只在内存等待审阅，最多30秒。

新建银行表单填入卡号及卡片提供的有效期、持卡人姓名。非空冲突先确认，缺失值保留原输入；已有分段姓名即使与完整姓名相同，也需确认后才能替换。标题、CVV／PIN、备注、存储目标不属于扫描写入字段。扫描不能可靠区分信用卡、借记卡和预付卡，用户必须明确选择类型，再经原保存按钮写入。证件新建页提示另开银行卡页，返回后保留原未保存证件；已有项目和其他编辑流程不被扫描覆盖。

扫描的卡号、姓名和有效期不进入导航参数、Intent 或 Android／Compose SavedState，表单与嵌套文本控件均受保护。设备用例在真实控件输入后递归核对 `SaveableStateRegistry.performSave()`，并以正常保存的标题作正向对照。锁定、后台、宿主卸载、路由变化与编辑器所有者更换撤销未完成结果；过期锁代不能重新填入。

EMV 读取器无新增依赖，执行 PPSE／已知支付应用 SELECT、GPO 与卡片声明的记录 READ RECORD，不请求PIN、CVV、余额或交易历史，不发送 VERIFY／GENERATE AC，不把芯片UID当卡号。受保护居民身份证及不公开PAN的卡片不在支持范围。GPO可能改变芯片内部计数，不能承诺卡内零状态变化。响应缓冲清零，卡片／表单对象的诊断字符串隐藏字段。

协议有界：最多6个识别应用、16条记录、48次交换；单次响应数据2048字节（含状态字原始帧2050）、累计原始响应16384字节；TLV深度8／节点128；PDOL128字节／32项；一次6C修正、四次61续取。IsoDep超时1200毫秒，另有10秒协作截止与锁代／读取代校验。进程级worker槽直到实际I/O退出才释放，独立关闭协程不随Activity销毁取消；这部分仅静态审阅，未注入真实硬件永久阻塞，不能声称强制终止底层调用。
