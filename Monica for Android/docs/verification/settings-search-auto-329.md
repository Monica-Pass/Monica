# 设置定义与自动搜索 — 1.0.329

2026-11-19。普通版 code12、canonical F-Droid code36，均未发布。

## 改动

根因是设置界面与搜索目录分别维护，新设置没有自动进入手写目录。现改为共享不可变 `Setting` 定义：标题、静态说明、目的地、父入口和 Plus 可见性只声明一次，界面读取同一份文案，搜索自动枚举所有活动定义。标准行、开关、子页行、定制分组、选项/排序控件和底部导航配置要求传入定义，不接受原来的裸标题签名；自定义布局也从定义取得静态文案。父结果按子项路径自动继承名称和说明，不再手写逐项搜索列表。

覆盖 HyperOS 及模块子项、保持解锁、默认填充库、黑名单、局域网同步、图标、底部导航、预览开关和回收站设置等。普通版 175 个基础定义、Plus 启用后 177 个；F-Droid 分别 174 / 176 个。每版另有六个仅保留于旧自动填充页面的定义，明确标记 legacyOnly，不向当前 V2 页面提供无效结果。

搜索只读资源，不读取设置值、账号、数据库名、密码或自定义字段内容。动态状态/选择值使用不入索引的内容行。HyperOS 的受保护子项定位开发者入口，仍经原身份验证；隐藏子项定位可见父入口，不自动改开关、申请权限或执行动作。F-Droid 原来保留的无功能 OneDrive 行和搜索结果移除；Quick Setup 的 F-Droid 导入差异保留。

新增设置遵循 `docs/development/settings-search.md`：定义一次并交给标准组件，自动进入搜索；新页面补实际导航检查。普通仓库 AGENTS.md 已记录约定。任意手写 Text/clickable 控件仍须遵循此约定，不能从任意文案自动推断安全跳转；这不是扫描数据库或运行隐藏页面生成索引。

## 失败与边界

- main01 的 Android 测试编译失败：两个排序夹具仍使用旧组件签名，迁移到必填设置定义后通过。
- main02 首批页面回归 25/27，不能称首批全绿。旧测试查找已移除的排序箭头，另一个未展开预设字段“更多选项”就查找占位提示；任务前源码已使用自定义无障碍排序动作和折叠选项。改用实际动作/展开入口，保留顺序、持久化、必选、取消断言，并补齐该夹具的用户名开关恢复。最终普通 27/27；FD 结果见下文。未改生产逻辑掩盖失败，原日志和原测试源码保留。
- FD 首批修正后回归在前 20 项通过后，于第 21 项被系统中断。崩溃日志确认 `system_server` PID833 在 MuMu 窗口管理 `TaskUtils.shouldIgnoreDesktopHomeOcclusion` 中 SIGSEGV，随后 shell instrumentation 退出时也发生 native 崩溃。系统框架自行恢复至 PID63291，原应用和用户清单保留；没有重启/清数据/改源码/换 APK，原中断不计完整通过。未声称修复 MuMu 系统问题，相关时间段原日志另存文本。
- FD 恢复后的完整 fd03-regression 为 26/27，61.011 秒。第 18 项 `unavailablePlusRouteStaysDisabledAtLargeText` 在滚动前报 `No compose hierarchies found`，同期日志记录从上一竖屏夹具切换至横屏；完整因果仍未确定。其余 26 项通过，包含先前被系统中断的第 21 项。保留相同主/测试 APK，单独运行该失败项一次通过（fd04-focused，0.784 秒），此前 fd02 批次该项也通过。没有继续重复整批直到偶然通过，没有改生产代码或断言；记录分批覆盖及未解决的夹具/环境稳定性边界。
