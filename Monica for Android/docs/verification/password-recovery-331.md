# 1.0.331 主密码独立恢复验证

状态：两版实现与本报告范围内的验收已完成，尚未提交本轮实现或发布。测试不能保证任意历史库、所有机型与所有系统改动均可恢复。

## 实施范围

普通使用继续采用原 Keystore 存储。仅在故障页由用户输入原主密码并再次确认后，使用现有认证恢复封装恢复原 MDK 和配置。新的独立加密文件先写入、读回验证，再发布独立 selector；数据库、原配置、原 recovery.json 和 alias 保留。未实施自动整库迁移、默认后端切换或首次升级强制提示。

密码后端继续使用原版本化 KDF 和认证加密，不降级参数。凭据代次和配置修订协调跨进程写入；旧句柄、取消及超时结果不能继续授权。独立后端暂不提供指纹重新绑定或重置全部数据。主应用、系统自动填充及独立输入法复用同一存储入口。

迁移识别集中到 `LocalCipherEnvelope`，修正读取支持而迁移遗漏的外层空白和嵌套字段情况。完整库测试另发现附件容器在同进程恢复后仍保留旧配置句柄；现按实际 selector 和密码会话身份重建后续操作所需缓存，旧操作仍由原安全检查拒绝。

- 普通版与 canonical F-Droid，未发布 1.0.331（普通 code12、F-Droid code38）。修改前基线已分别推送 `92e04e2a9969cff4d0a7f739684784b2bd4ea281`、`74d41ba44286b4fbea3a2fb2d919af20c86b6b1e`。

## 失败和修正

- 保留最初3项迁移负向复现。迁移仍保留未知或不可读值，未放宽错误门控。
- 完整库首次恢复发现附件旧句柄，修复后原字段与附件字节、同进程重认证、冷启动及备份恢复通过。复测前仅将本任务 fixture 的 selector 暂存回原选择，原配置/恢复文件和数据库哈希核对；失败的独立加密候选文件保留。
- 早期 UI 批次普通44/46、F-Droid43/46等失败保留。等待实际 Compose 页面后，F-Droid46/46通过，普通失败项在同APK独立通过；不能称早期整批全绿。
- 一次输入法测试被 Android 内部运行时重启中断，保留 `SYSTEM_RESTART`；MuMu 宿主进程未重启，原用户及数据仍在。未取得 system_server 崩溃原因，不能归因于应用或宣布系统问题已修复。后续同一应用包输入法认证与自动填充通过。
- 输入法夹具的状态最初被横屏键盘/原生 ActionBar 遮挡，修正夹具可见性后得到明确 `user=OK password=BAD`。三条合成记录共用用户名，原脚本按用户名选中了其他记录；只将选择条件改为原记录的唯一标题后两版真实键盘填写通过。保留失败，不删减账号/密码断言，不修改生产填写逻辑。冷输入法方法单独启新进程，避免把前一方法已解锁的状态当作冷启动。
- JVM 局域网测试原依赖磁盘 Steam 单例；改为通过已有注入参数提供独立内存库，17项原断言保留并通过。
- 旧 R8 AndroidX runner 依赖被裁剪，未修改生产混淆规则。正常升级先采用真实 Release UI；随后单独编译仅依赖 Android 框架的同签名 instrumentation，在实际 Release 进程中移除提供器并启动真实 Activity。它不调用应用内部符号、不替换生产恢复实现、不删除 alias；每次 force-stop 后该进程内注入结束。测试编译增量缓存故障仅对本次测试编译禁用增量，不改全局设置。
- 首次回退比较把版本/会话普通偏好变化也计为失败。后续保存逐文件前后哈希，明确只有普通版本/会话标记变化；加密配置及恢复材料字节不变，返回331后原 corpus 可读。
- F-Droid 实际 Release 降级被 Android 拒绝。ADB 此次进程返回0，输出同时含传输成功与安装失败，旧驱动误报 installed；真实页面断言随即失败。核对包管理器版本和 APK 哈希后确认仍是331，修正驱动拒绝失败文本并核对已安装APK哈希；回查所有安装回执，仅这一份包含失败。普通版实际330拒绝新格式、两版Debug旧代码拒绝新格式分别留证，不将FD系统拒绝称为旧Release代码通过。

## 最终证据

[结构化证据](password-recovery-331-evidence.json)记录构建哈希、不同设备方法与原始回执SHA；[普通版设备回执](password-recovery-331-main-device.txt)和[F-Droid设备回执](password-recovery-331-fd-device.txt)只整理空白，原始日志、失败记录、合成备份和测试包另留本地。

本轮每版28项JVM、61个不同设备方法取得通过记录。最终生产代码覆盖49核心、4系统入口及6完整corpus阶段；另有2项此前的真实恢复Activity测试，最后又以实际Release按钮与冷解锁验收恢复页面。不同批次和此前失败单独记录。51共享路径字节一致，21配置各5条新增文案完整；普通5240/FD5248项Release生产输入仍与构建时哈希一致，未用测试包更新冒充主包更新。F-Droid元数据与6脚本检查通过。

两版正常升级和故障恢复后的原58个ZIP成员分别逐字节对比，含13份196613字节二进制附件、13份987字节图片。恢复后多出的新记录与其删除前的回收站记录来自明确的测试操作。完整corpus便携备份也导入另一UID的实际330 Release，来源安装alias未提供；便携导入按原有规则脱离原生云库身份。

## 未覆盖与使用边界

本轮没有物理 TEE、厂商真机、真实 OMK/KeyMint 切换、硬件不可导出 Passkey、掉电或真实磁盘耗尽验证。进程内移除提供器是独立路径的故障注入，不等同于所有系统后端故障。

独立后端依赖仍有效的恢复材料和原主密码。此前唯一依赖的随机设备密钥若已永久丢失且没有独立封装或可读备份，软件不能重建它。仅凭配置恢复成功不能宣称所有历史记录可读。应用私有恢复文件也不替代离机加密备份。

未提交或推送本轮实现、打标签、发布或交付 APK。已归档合成夹具并移除本任务测试用户与辅助包；原0/10/11/12/16用户及应用数据保留。MuMu宿主PID保持不变并继续运行，仅关闭本任务ADB服务。
