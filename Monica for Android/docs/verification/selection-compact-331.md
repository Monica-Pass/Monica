# 多选菜单恢复紧凑设计（1.0.331，未发布）

2026-11-26，普通版。按用户要求恢复紧凑的无独立背景图标按钮，保留此前调亮的主题菜单底色。本记录取代 [此前圆形按钮方案](selection-contrast-331.md) 的外观结论；此前测试记录作为历史保留。

## 实现

- 共用 SelectionActionBar 使用透明 IconButton，按钮布局恢复 40dp、菜单圆角 28dp、内边距横向 8dp／纵向 6dp，计数恢复紧凑文字布局。Material 默认按压水波纹保留，非按压状态没有按钮实色圆底。
- 菜单混色和表面分离算法与修改前完全一致，继续无外圈描边。普通及删除图标直接针对菜单底色计算可读前景。
- 操作回调、数量／关闭固定可见和窄屏横滑操作区保留；无新增字符串、依赖、数据格式或存储逻辑。
- 两版共享生产组件与既有测试调整字节一致；发行说明更新原条目，不重复追加，也不附验证报告或操作指南。
