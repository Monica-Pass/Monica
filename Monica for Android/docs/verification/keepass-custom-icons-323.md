# KeePass 自定义图标验证（1.0.323，未发布）

日期：2026-10-30。版本：普通版 1.0.323。

## 修复与边界

KDBX 的 CustomIcons 图片池和条目/分组 UUID 原本已经解析、保存。缺口在 Monica 标准界面的图标读取路径。本次继续使用 Monica UI，通过已解锁进程会话的 UUID 映射读取原库图片：普通密码卡、组合密码卡、密码详情、编辑预览、密码库条目、总览密码行/选择行，以及密码库分组行。

Monica 明确自选的品牌图标、上传图标或 Emoji 保留优先级，原库图片先于自动品牌、favicon 和应用图标。没有图标池时立即回退；读取图标不加载文件、不执行 KDF，也不为显示图标构建完整详情浏览模型或 Room 索引。

图片仅在内存中解码，不冒充 Monica 上传文件名，不写入本地图片文件或数据库图标字段。会话替换、失效或缓存淘汰通知界面刷新；KDBX 锁库及应用整体锁定时隐藏图片。编码大小限制为 2 MiB，解码前检查尺寸并采样缩小；缺失引用、重复 UUID/歧义分组路径、无法解码的图片安全回退，原库数据不因此删除或重建。未增加标准表单中的原库图标池管理功能。

本次未修改 KDBX 文件写入、UUID 冲突、附件、历史、所有权、KDF、Keystore 或恢复策略。已有 UUID 的不同图片不能通过 Monica 写入 API 直接覆盖，保留原有冲突保护。

## 最终构建与设备验证

构建命令：`gradlew.bat :app:assembleDebug :app:assembleDebugAndroidTest -PincludeX86TestAbi --offline --max-workers=2 --console=plain`。

最终主程序与测试包构建成功：1m 17s。

复用公共 `Monica_Issue136_API_32` / `emulator-5582`，覆盖安装且不清除应用数据。完整运行 `KeePassCustomIconUiTest`（5 项）与 `KeePassMonicaEditorUiTest`（1 项），结果：`OK (6 tests)`，75.687 秒。

- 从合成的 300 条 KDBX 直接建立标准 Monica 模型，原库图片在密码卡、组合卡、详情图标、共享密码库图标、总览密码行和分组行显示，优先于可自动匹配的 GitHub 品牌图标。显示不增加文件读取或提交次数，Room 密码索引保持为空。
- 应用整体锁定及 KDBX 单库锁定后图标消失；读图标不自动解锁或写库。
- 模拟外部 KeePass 修改同 UUID 图标的图片并重新加载原库，界面像素更新；Monica 自选 Emoji 能覆盖原库图片，恢复默认后重新显示原库图片。错误数据库/条目身份不取到图片。
- Monica 原库保存一次文件提交，重新开库后原条目 UUID、图标 UUID、池图片及历史图片保留，无伪造的上传文件名或 Room 图标镜像。
- 真实 Monica 编辑表单显示原库图片，修改标题后保存至原库且图片保留；锁库撤销未保存草稿，原文件保持不变。
- 截断 PNG、超限编码、较大尺寸 PNG、缺失池引用和重复分组路径回退/采样符合预期。歧义路径的分组只按稳定且唯一的 UUID 显示图标；只读检查不写文件。

第一轮普通版测试有 1 项因测试夹具试图调用现有 API 覆盖同 UUID 的不同图片而被冲突保护拒绝。只修正该合成夹具为模拟外部原库修改，未放宽生产写入保护；保留初次日志，随后两版均以最终源码完整通过 6 项。
