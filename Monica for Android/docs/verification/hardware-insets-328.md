# 1.0.328 物理密钥页面状态栏适配验证 — 普通版

真实 Activity 窗口的几何回归与列出的 18 个不同设备方法取得通过结果；初次失败保留。完整窗口视觉验收与 MainActivity 的 Passkey FAB 到物理密钥页导航未取得成功证据。最终设备清理仍等待主代理核对，版本未发布。

## 改动与安全边界

硬件生产改动只有 `HardwareSecurityKeyActivity` 中的一条 `enableEdgeToEdge` import 和 `super.onCreate` 前的一次调用。去掉这两行后与本轮冻结的原 Activity 内容一致；两版当前 Activity 和 HardwareKeyUiTest 分别字节一致。原 `FLAG_SECURE`、认证、来源验证、取消、USB/NFC 生命周期及 HardwareKeyScreen 的安全区域留白没有因本轮适配改变。

新回归实际启动私有硬件 Activity，要求前台、竖屏且系统状态栏真实可见、inset 大于零，再以同一窗口坐标量取 content、标题和关闭按钮。管理页覆盖真实重建与关闭，CREATE/GET 窗口覆盖缺失请求时提交禁用、显式取消及 API34+ 对应的取消异常。没有成功 USB/NFC 认证或注册的结论。

## 安全预览与未完成的视觉观察

独立本地 instrumentation 直接创建真实私有管理 Activity，核对冻结安装包、签名、API/ABI，保持已有 `FLAG_SECURE`、前台焦点、RESUMED 和竖屏，最后观察自己创建的 Activity 销毁。普通大字深色 25s 两次各 250 个样本通过；55s 普通大字深色、普通正常字号浅色和 FD 大字深色的成功回执各记 549 个样本。FD 另有 25s/250 样本成功；各运行标签与样本数保留在结构化结果中。

普通最早两次 preview 在竖屏前提失败，尚未创建 Activity；原回执保留。后续由所属设备夹具调整竖屏与临时 rotation 设置，preview 探针本身没有改方向、字号、主题、偏好、锁状态或安全旗标。55s 延长只属于本地预览探针，未改变应用源码或几何断言。

**本轮主机截图观察显示桌面/启动器或窗口遮挡，没有成功的完整硬件窗口视觉验收。** preview 探针没有截屏，成功只证明它检查的窗口状态及销毁；不能据此宣称主界面 FAB 路径、浅/深色全窗口视觉或物理密钥可用性已经验收。组件截图、Compose reference 渲染以及本地 M3E 八帧浅/深色草图预览也不替代该验收。图片、Canvas、原始 UI 快照只留在本地忽略目录，公开报告不引用图片。
