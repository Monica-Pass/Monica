# 笔记悬浮工具栏修复（未发布 1.0.331）

用户截图中的整块黑底来自旧布局：工具栏作为普通 Column 子项占据底部空间，正文滚动视口提前结束，露出页面背景。普通版和 canonical F-Droid 现在使用底部覆盖层，仅工具栏自身保留圆角主题背景与阴影；键盘和导航栏避让在共同容器处理。

普通编辑模式的滚动视口延伸到工具栏后面，在滚动内容末尾保留可滚动留白，并以实际测量的工具栏高度修正父容器的焦点滚动可见区域；内部文本框保留原滚动行为。全屏模式共用悬浮工具栏，正文文本框留出安全空间以保证末行光标可见。预览不显示工具栏。未修改保存、加密、认证或数据库逻辑。
