# 1.0.331 滑块滚动与触觉反馈验证

2026-11-25，普通版与 canonical F-Droid，未发布。DPI、生成器、自动填充生成器、图片压缩、自定义配色及 WebDAV 设置的 8 个调用文件、11 处滑块统一使用圆润填充轨道和花形滑钮。各调用处仅更换组件导入，原范围、回调和提交时机保留；DPI 松手应用，生成器拖动期间保留已有结果、松手后重新生成。

滑钮按实际移动距离旋转，左右拖动及 RTL 方向对应。应用减少动画或系统关闭动画时不旋转。用户跨刻度触发轻触觉，连续范围按百分之一分档，最小间隔 32ms，不积压补震；应用触觉开关和系统设置生效，外部值恢复、禁用控件不震动。继续使用 Material3 输入、键盘和无障碍动作，实际组件布局高度至少 48dp。

## 失败与修正

首轮 F-Droid 四项中两项完成通过：触摸高度实测只有 38dp；DPI 测试将 ModalBottomSheet 挂在模拟触觉的 1dp LocalView 上，触发宿主 detach 异常，进程未正常完成。修改 DPI 夹具使用真实 LocalView，并保留真实滑块断言。普通第二轮五项四过一失败，外层 heightIn 仍不能扩大 Material Slider 的内部测量高度。第三轮将 track slot 布局改为 48dp、38dp 视觉轨道居中，最终两版各五项全过；未删减高度断言。前序日志均保留，不能称首轮全绿。

首轮 F-Droid 全屏截图受 MuMu 广告遮挡，不计视觉验收；最终普通 DPI 和 F-Droid RTL 等全屏截图已确认无遮挡。原生组件帧和生成器组件截图只证明相应组件绘制。审计脚本首次额外要求所有源文件末尾换行，但上游复制的形状文件本来没有末尾换行；保留该原字节，使用 Git 空白检查和精确源码快照核对，不把脚本断言失败算作构建失败。
