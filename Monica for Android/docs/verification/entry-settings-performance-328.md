# Android 328 入口设置等待优化验证

2026-11-15，普通版，未发布 1.0.328。

自动填充选择器与输入法解锁入口改为异步等待一份真实设置。请求在安全存储准备之前绑定生命周期，仅当原请求仍有效、锁定代次未变且页面已恢复前台时交付一次；后台、返回、销毁、超时和读取失败不会按默认设置放行。保留目标自动填充授权、安全存储准备及原有单槽加密读取 worker。没有更改认证算法、KDF、存储格式或用户密码策略。

## 对照与回归

- 旧普通版在延迟设置首份数据时，真实自动填充 Activity 主线程停在 runBlocking，心跳断言失败；修改后同一延迟条件下主线程响应。此证据证明消除了该同步等待，不代表所有启动都更快。
- 两版各 134 项相关 JVM 测试全部通过。设备为 MuMu API 35 / x86_64，各 28 个不同 Debug 方法获得通过结果：真实 picker 的延迟及六项生命周期、九项 helper、四项旧密码/取消/慢验证、两项安全存储启动超时，另六项实际独立 :ime 进程测试。包括 Back、后台、锁定、旋转重建及实际自动锁定值。
- 本版混淆 Release 构建成功；保留旧 Release 合成库，以同包名、同签名 install -r 覆盖升级，无卸载或清数据。原密码、原记录密文与类别 ID、新加密写入及不同 PID 冷读取通过。
- 实际主界面原密码解锁、列表打开、V1 加密 ZIP 导出、系统文件选择器导入均完成。备份含两条合成记录，只移除自有新记录后还原一条、跳过已有记录；平台探针对还原结果、原密文保留及可解密性再次核验。记录预置和写入验证使用生产加密及 SQLite 夹具，不声称全由编辑器建立。
- 实际 R8 包的 picker 与独立 :ime 入口各通过原密码认证和取消，共四项。IME 验证成功广播及独立进程确认；picker 认证后显示原合成记录，取消关闭密码页面且无成功结果/记录展示。没有额外添加 R8 keep 规则。
- 九份共享源码/测试逐字节一致，APK SHA、签名、ABI 与各项回执摘要见同名 result.json。

## 初次失败与修正

保留普通版初始主线程阻塞对照；JVM 首轮 133/134，旧输入法守卫期待缓存密码解密，而既有生产代码已重读当前 DAO 行，更新守卫后第一版又因截掉自己所断言的方法名失败，最终保留原范围并检查实际读取与授权顺序。生产输入法服务未因修守卫而更改。

设备首轮主进程测试 10/10 因本地 manifest 合并到 :ime 而失败，修正为分别打包主进程/IME 测试；接着普通版 6/10 通过，四项密码回退夹具尝试用当前新建接口创建单字符密码，被当前最小长度策略拒绝。改为独立生成历史 PBKDF2 凭据后，原短密码、失败、取消和迟到成功断言均通过；未降低生产密码规则。后续普通主回归 20/20（另两项已通过），F-Droid 主回归 22/22，最终各六项 IME 通过。

本地 R8 UI 脚本早期遗漏繁体「確定」并未等待按钮本身启用，修正目标匹配和状态等待后通过，未改生产逻辑。MuMu 推广页面曾抢焦点；F-Droid R8 pickerAuth 首轮在最终观察时显示商店登录页而失败，同应用及同测试包在无遮挡状态下复测通过，并不称首批全部通过。平台 uiautomator 有写出 XML 后退出 139，后来只读取本次新生成且可完整解析的 XML，并在手工流程输入前验证前台包名。这些运行不冒充应用成功，原日志及回执留本地任务目录。早期外部探针 APK 没有为每次迭代保存独立副本；最终探针源码与产物保留。

## 范围

仅合成库、模拟器与选定路径；未验证物理设备、OEM、生物硬件、真实云账号或所有凭据类型。R8 系统入口测试直接启动内部 Activity，不等于第三方浏览器端到端自动填充验收。超时/错误由 helper 测试覆盖；真实 Activity 覆盖等待、返回、后台、锁定、重建及设置交付。仍保留逐项加密失效检查与后台锁定监听，不以性能为由放宽安全边界。
