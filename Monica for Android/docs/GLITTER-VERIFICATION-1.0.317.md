# Glitter / 闪耀形态验证记录（1.0.317）

> 2026-10-06：用户已决定暂缓 Android 客户端接入 Glitter。以下保留为先前实现与验证记录，不代表当前客户端功能；当前只提供 Sky、Multi、Power，MDBX 底层仍支持 Glitter。

状态：实现与双版本地构建、回归和性能测量完成；实体手机硬件认证及端到端体验仍未验收。本文不代表所有设备/所有操作均优于旧模式，也不是发布批准。

## 实现边界

- 新增第四档；保留 Sky、Multi、Power 的原有默认值与序列化顺序。
- 密码与随机密钥文件共同解锁；Argon2id 使用 512 MiB / 10 / 4。Glitter v1 不接受任意增大的导入参数。
- 不可降档的 policy v3、关键扩展和独立密钥包装 AEAD 域；普通兼容接口不能批量返回秘密。
- Android 使用真实强生物识别 CryptoObject 和逐次认证的硬件 Keystore 密钥保护本机凭据。Rust 的设备上下文是客户端信任边界，不是硬件证明。
- 原始授权最多 60 秒，退后台即锁定；不可用读取、写入或重复绑定延长。界面清除秘密及未保存草稿。
- 仅在原生数据库管理页操作；不建立普通 Room 秘密副本，不提供聚合列表、后台自动填充、秘密复制或解密附件文件导出。附件仅内存预览。
- 外部文件只能经用户确认导入独立的应用私有副本，不保持可写 SAF 链接。远程同步只能使用当前已认证原生句柄，过期不静默重开。
- 热态加速仅复用已认证的标题及分页元数据：64 MiB 标题预算和 32 MiB 分页预算，不缓存秘密载荷或授权决定。写入、事务、外部提交、换钥和锁定使缓存失效。

## 验证环境与可信范围

- Windows 11 Pro Insider Preview 10.0.27919 x86_64，Intel Core i7-12800HX（16 核 / 24 线程），系统报告 34,078,035,968 字节物理内存（约 31.74 GiB）；Rust 1.86.0 release 性能测试。
- 公共 Android API 32 x86_64 AVD `Monica_Issue136_API_32`，复用既有配置和数据盘。
- 原生测试执行真实 512 MiB KDF、SQLite、加密、JNI 与对象/附件操作。测试用设备上下文是合成数据，不能证明真实 TEE、StrongBox 或生物识别成功。
- 没有已连接的受支持实体手机。真实硬件成功、硬件密钥失效/重新登记和实际远程服务端同步尚未验收；不作整机速度、耗电或所有设备可用性承诺。

## 回归与最终构建

最终安全加固后的 `cargo test --release --workspace -- --test-threads=2` 已通过：1163 passed、0 failed、1 个既存忽略的性能测试。证据：`native-workspace-acceptance-final.log`。

最后 32 项 Glitter 专项测试含真实 512 MiB KDF、组合凭据与备用包装、错误因子、弱参数/超预算参数拒绝、过量包装/大字段预检、热态外部改写锁闭和缓存失效。超大 Argon2 参数测试先断言无派生预检拒绝，不执行故意耗尽内存的实验。

最终宿主动态库匹配 545 个 UniFFI 符号、242 个签名校验，contract version 30。Android arm64-v8a、armeabi-v7a、x86_64 三 ABI 均完整构建成功，分别验证 545 个必需符号，无缺失；均保留 GNU build ID。198 个原生构建输入在原生工作区与 F-Droid vendored 源码逐文件原始哈希一致，补丁反向 dry-run 通过。

普通版最终原生库的 API32 x86_64 JNI instrumentation 为 5/5 通过（18.811 秒）：真实 Glitter 组合因子创建/重新打开、256 条数据分页、缓存、修改/删除及受限接口拒绝，以及既有模式兼容。设备能力上下文为合成输入，不代表实际硬件认证。

普通版修订后统一 Debug / AndroidTest / engine-test 构建成功（4 分 12 秒），56 个相关 JVM suites 共 236 项通过，0 失败/错误/跳过。最终应用设备回归 30/30 通过（72.441 秒），涵盖登录/附件操作、会话退出/到期/竞态、滑块与编辑器、复制保护、屏幕保护和布局可达性。

## 同负载性能

比较使用相同组合凭据、每库 3000 个条目、每页 200 条、3 轮轮换模式顺序；每轮冷开库后首遍扫描，再连续测量 20 遍完整列表。另测 50 条写入，并验证更新后授权读取。最终测量前，所有协作代理明确确认暂停构建、设备测试与 Canvas 渲染，宿主无 cargo/rustc 测试进程；本机其他普通后台活动不作完全隔离保证。

下表取各轮相应数值的中位数；热态行取三轮各自 20 次扫描 p50 的中位数。所有时间均越低越好。“冷解锁”指关闭句柄后重新执行完整凭据/KDF 解锁，没有复用已认证会话；没有清空操作系统文件缓存，也不是手机冷启动测试。

| 原生负载 | Sky | Power | Glitter |
| --- | ---: | ---: | ---: |
| 完整冷解锁 | 9.78 ms | 1157.01 ms | 2422.87 ms |
| 解锁后首次完整分页扫描 | 74.48 ms | 76.77 ms | 78.24 ms |
| 缓存预热后完整分页扫描 p50 | 68.32 ms | 68.27 ms | 1.47 ms |
| 批量更新 50 条 | 23.84 ms | 22.29 ms | 22.17 ms |

热态列表相对 Sky / Power 约快 46.4 / 46.3 倍。Glitter 三轮热态 p50 为 1.677 / 1.473 / 1.466 ms，p95 为 1.753 / 1.614 / 1.686 ms；不是单个最好成绩。每轮 300 次分页命中，保留标题/页元数据约 3.51 MiB（预算上限 96 MiB）；这不含 KDF 的 512 MiB 工作内存、SQLite 和客户端开销。每轮更新后读取和策略授权的秘密读取均验证成功。

原始逐次样本：[最终 JSONL](verification/glitter-317/glitter-benchmark-acceptance-final.jsonl)。复现：在原生目录运行 `cargo run --release -p mdbx-ffi --example glitter_benchmark -- 3000 3`；精确测量应先构建，再在停止其他本任务负载后直接执行生成的程序。

初版只缓存标题时，热列表中位数约 Glitter 73.57 ms、Sky 73.07 ms、Power 72.62 ms，没有稳定优势；该失败结果保留为 `glitter-benchmark-final.jsonl`（历史文件名中的 final 不代表最终版本）。分页缓存诊断 `glitter-page-benchmark-final.jsonl` 明显改善，但与 Kotlin 编译重叠，因此不作为最终性能结论。两份历史数据与最终数据一起保存。

这些数字只针对原生重复分页浏览。冷解锁、持续写入、首次读取、端到端 UI 和远程同步均不能由热缓存成绩推断。更高 KDF 成本与更严格认证仍会牺牲启动时间、内存和便利性。

## 可追溯性

- 原生契约：`mdbx/docs/TIGA-GLITTER.md`；F-Droid 带同源副本。
- 两版引擎目录中的 `GLITTER_SOURCE_MANIFEST.json` 固定源文件原始 SHA-256、基线提交和可重放补丁。
- 主版 `MDBX3_RUNTIME_PROVENANCE.json` 与 F-Droid `MDBX3_SOURCE_PROVENANCE.json` 记录当前运行库信息；旧验证留在 `.pre-glitter.json`，不沿用为本次结果。
- 原始构建/测试日志保留在工作区 `.codex-tasks/glitter-317/`。最终关键结果、失败尝试与性能逐次样本同时保存到本报告旁的 `verification/glitter-317/`，并由 provenance 记录哈希。
- 两版共六个产品 APK 均逐个从压缩包读取 `libmdbx_ffi.so` 计算 SHA-256，确认等于各自构建输入；剥离前后 GNU build ID 一致。详见 `packaged-runtime-acceptance-final.json`。普通版 versionCode 12、F-Droid 24；版本保持 1.0.317（普通版 Debug 附既有每日构建后缀）。
- 可编辑本地设计及预览见 [设计记录](design/glitter-317/README.md)。生产 `FLAG_SECURE` 不因截图测试关闭。

## 尚需实体手机完成的验收

1. 64 位且内存满足门槛的手机，已登记强生物识别，Keystore 认证由 TEE/StrongBox 强制执行。
2. 实际创建、关闭、重新解锁、修改登录条目及附件；检查 60 秒到期与退后台清屏。
3. 取消/失败的认证不能获得凭据；生物识别变更、密钥丢失与换机离线重登记能给出正确结果。
4. 大库滑动、搜索、冷热解锁、内存压力及发热耗电实测；使用真实远程端点验证授权过期后的同步行为。
